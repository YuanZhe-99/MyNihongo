# lib/features/writing/services/writing_rubric.dart

应用自己能测出来的、关于一段写作的那些事实。

**它在每一台设备上都会运行，有没有模型都一样**，而且它是 AI 提示写在上面的底子，而不是没有模型时
的替代品。学习者在任何一部手机上都有权得到同样的测量结果；模型加上的是一句"接下来可以试什么"，而
那也正是它被允许加的部分。

这里没有任何一项是分数。没有总分、没有百分制、没有及格线，因为 JLPT 没有作文，为它编一个分数等于
应用断言了一件没有考官会断言的事。

## 声明

| 声明 | 种类 | 层级 | 用途 |
|---|---|---|---|
| library header | library doc | B | 不用模型也能测量一段写作。 |
| `writingRubricWordTarget` | 常量 | B | 一段写作希望用到本单元的几个词。 |
| `WritingRubric` | 类 | B | 应用测出来的、关于一段写作的事实。 |
| `sentences`、`wordsUsed`、`wordsWanted`、`grammarUsed`、`tokensAtLevel`、`tokensPlaced`、`unreadable` | 字段 | B | 各项测量结果。 |
| `isEmpty` | getter | B | 有没有可报告的内容。 |
| [`levelShare`](#levelshare) | getter | A | 已定位的词里，处于目标级别或更简单的比例。 |
| `metWordTarget` | getter | B | 有没有达到本单元的用词目标。 |
| [`build`](#build) | 静态方法 | A | 测量一段写作。 |
| [`promptLines`](#promptlines) | 方法 | A | 用提示词能承载的行，说出测到了什么。 |

## 文档

### `double get levelShare` <a id="levelshare"></a>

- **种类：** getter
- **用途：** 已定位的词里，处于目标级别或更简单的比例，0 到 1。
- **输入：** 除接收者外无。
- **返回：** `double`；分母为空时返回 1。
- **副作用：** 无。
- **算法：** `tokensAtLevel / tokensPlaced`，分母为零时取 1。
- **用法：** 写作页面的清单那一行，以及 `promptLines`。
- **注意：** 一个词都定位不到时是 **1，不是 0**。一份因为查不到某些词就责怪学习者的清单，测的是词
  库而不是写作——同样的道理贯穿 `build`：目录定位不到的词记为"读不出来"，而不是记为太难。不知道一个
  词是什么，和知道它超出了级别，是两个不同的发现，只有后者是关于学习者的。

  这项测的是"在自己能力之内"，不是"跟自己的级别一样难"：一个以 N1 为目标的人写出的一整句 N5 词，
  得分就是 1，因为句中每个词都是 N1 或更简单。一份奖励难度的清单，会推着学习者去写超出自己的东
  西，而那正好和这个练习的目的相反。

### `static WritingRubric build({required List<SentenceAnalysis> analyses, LessonUnit? unit, ContentCatalog? catalog, required JlptLevel level})` <a id="build"></a>

- **种类：** 静态方法
- **用途：** 测量一段写作。
- **输入：** `analyses`，每句一个；有的话还有 `unit`；`catalog`；以及学习者要达到的 `level`。
- **返回：** `WritingRubric`；分析为空时返回空的。
- **副作用：** 无。
- **算法：** 走遍每一个分析，收集语法匹配、数出读不出来的词，并对每一个已定位的词记下本单元是否需
  要它、它的级别是否不高于目标。
- **用法：** 写作页面，每次检查时。
- **注意：** 用到的词是从**分词结果**里数的，不是在文本里搜的，所以变形也算：写了「食べました」的
  人用了「食べる」。语法同理，来自分析器自己的匹配而不是字符串搜索——这件事应用已经有比搜索更好的
  答案了。

### `List<String> promptLines(String level)` <a id="promptlines"></a>

- **种类：** 方法
- **用途：** 用提示词能承载的行，说出测到了什么。
- **输入：** `level`——写出来，好让模型知道"符合级别"指的是什么。
- **返回：** `List<String>`；空的清单返回空列表。
- **副作用：** 无。
- **算法：** 每一项有话可说的测量结果各一行。
- **用法：** `PracticePromptBuilder.forRubric`。
- **注意：** **是英文，而且是故意的：这些行进入提示词，永远不上屏幕。** 屏幕上通过 ARB 词条用学习
  者自己的语言渲染同样的数字；这一份是给模型的，把两者分开正是为了防止一次翻译改动悄悄改写了一条
  提示词。

  正因为这些结果在提示词里，模型从来不会被问"这段写得好不好"——它看到的是应用测出的东西，被问的是
  接下来该怎么办。这项任务的规则禁止重新评分，而这条规则和本应用里其他每一样生成内容遵守的是同一
  条。
