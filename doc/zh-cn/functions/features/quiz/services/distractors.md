# lib/features/quiz/services/distractors.dart

挑选选择题所提供的错误选项。

干扰项必须**错得可信**。太容易，题目什么都没测到；碰巧也正确，题目就无法作答。下面每条规则都先收紧、必要时才放宽，而且每一条都可能返回不足——调用方会丢弃该题，而不是拿随便什么东西去凑数。

按内容库分述的理由见 [`../../../../features/quizzes.md`](../../../../features/quizzes.md)。

## 声明

| 声明 | 种类 | 层级 | 用途 |
|---|---|---|---|
| 库头 | 库文档 | B | 挑选题目所提供的错误选项。 |
| `distractorCount` | 顶层常量 | B | 一道选择题提供几个错误选项。 |
| `Distractors` | 类 | B | 挑选错得有道理的错误答案。 |
| `forMeaning` | 方法 | B | 找出词义可能与之混淆的词。 |
| `forWriting` | 方法 | B | 找出写法可能与之混淆的词。 |
| [`forKana`](#forkana) | 方法 | A | 找出可能与之混淆的假名。 |
| `_confusable` | 方法 | B | 读取注释中列出的易混假名。 |
| `_sameRow` | 方法 | B | 找出与它同一行的假名。 |
| [`_widen`](#widen) | 方法 | A | 从逐步放宽的筛选中取候选。 |

## 文档

### `List<KanaEntry> forKana(KanaEntry entry, {int count})` <a id="forkana"></a>

- **种类：** 方法
- **用途：** 找出可能与之混淆的假名。
- **输入：** 被提问的假名，以及需要几个错误选项。
- **返回：** `List<KanaEntry>`，可能不足。
- **副作用：** 无。
- **算法：** 先用内容库自带的 `confusableWith` 列表，再是同一行，最后是任意——全程**按罗马字**去重。
- **使用：** 三种假名模式。
- **说明：** 易混列表正是关键：シ与ツ、ソ与ン、ぬ与め，才是学习者真正可能犯的错，因此它们是值得提供的错误答案。按罗马字而不是按假名去重，正是防止じ和ぢ同时出现的机制——两者都是「ji」，同时提供两者的罗马字题就有两个正确答案。

### `List<VocabEntry> _widen(List<bool Function(VocabEntry)> filters, int count)` <a id="widen"></a>

- **种类：** 方法
- **用途：** 从逐步放宽的筛选中取候选。
- **输入：** 由优到劣的筛选条件，以及要取几个。
- **返回：** `List<VocabEntry>`，可能不足。
- **副作用：** 无。
- **算法：** 按顺序遍历筛选；把每条筛选的匹配打乱后取用，直到取满。
- **使用：** `forMeaning` 与 `forWriting`。
- **说明：** 放宽而不是在第一条筛选处失败，是一个刻意的取舍。同级别、同词性的干扰项是最好的一种，但一道只有两个选项的题比一道第三个选项略容易的题更糟——所以放宽的是筛选，而不是丢弃题目。每条筛选的匹配都会先打乱，因此同一个词不会总是抽到同样三个错误答案。
