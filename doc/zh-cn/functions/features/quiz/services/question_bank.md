# lib/features/quiz/services/question_bank.dart

一个单元能出的全部题目，以及从中的加权抽取。

覆盖整个级别的测验会打乱该级别的条目并取二十道，这会让一种题型出现的概率取决于它的条目有多常见。而一个单元小到可以把题池整个建出来再从中挑选——差别正在于此。

使用方：`quiz_page.dart`。

## 声明

| 声明 | 种类 | 层级 | 用途 |
|---|---|---|---|
| `QuestionBank` | 类 | B | 一个单元的题目。 |
| `QuestionBank.isEmpty` | getter | B | 该单元是否什么都没产出。 |
| [`QuestionBank.build`](#build) | 方法 | A | 构建一个单元能出的全部题目。 |
| `QuestionBank._authored` | 方法 | B | 把手写题变成一道测验题。 |
| [`QuestionBank.draw`](#draw) | 方法 | A | 从题池中抽出一次会话的量。 |

## 文档

### `static QuestionBank build({...})` <a id="build"></a>

- **种类：** 方法
- **用途：** 构建一个单元能出的全部题目。
- **输入：** `unit`、`catalog`、一个 `generator`、已启用的 `modes` 与 `locale`。
- **返回：** `QuestionBank`。
- **副作用：** 无。
- **算法：** 三个来源，按此顺序——该单元的目录条目以每一种已启用模式出题、它自己的句子跑过各语法模式、为它写的题目——并按条目、模式与题面去重。
- **用法：** `quiz_page.dart` 处理 `UnitSource` 时。
- **说明：** 之所以去重，是因为同一个句子可能从两个方向进入题池——作为目录例句，以及作为单元句子——那样它会在一次会话里被问两次。手写题是唯一带说明的一类。

### `List<QuizQuestion> draw(int count, {...})` <a id="draw"></a>

- **种类：** 方法
- **用途：** 抽出一次会话的题目。
- **输入：** 抽多少、学习者的 `progress`，以及一个 `random` 以便复现某次抽取。
- **返回：** `List<QuizQuestion>`。
- **副作用：** 无。
- **算法：** 按条目加权采样——没有记录权重为三，从未答对为二，其余为一，手写题再翻倍——每个条目取一道题，直到取满或条目用尽。
- **用法：** `quiz_page.dart`。
- **说明：** **每个条目至多一道题。** 十二道题应该是十二件不同的事，而不是同一个词被问六遍；正是这条约束让加权变得有意义，而不是变成反复追问最难的那个词。`random` 参数的存在，是为了让失败的会话能在测试里复现。
