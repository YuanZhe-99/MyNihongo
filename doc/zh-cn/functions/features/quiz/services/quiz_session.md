# lib/features/quiz/services/quiz_session.dart

把一次测验从第一题运行到总结：队列、判分、重排与计分。

写入进度是一个**回调**而不是依赖，因此该文件不 import 任何存储，测试也能精确观察它本会写入什么。

## 声明

| 声明 | 种类 | 层级 | 用途 |
|---|---|---|---|
| 库头 | 库文档 | B | 运行一次测验。 |
| `maxRequeues` | 顶层常量 | B | 一次会话中答错的条目最多回来几次。 |
| `QuizOutcome` | 类 | B | 一次作答的结果。 |
| `QuizSummary` | 类 | B | 一次已结束的会话，供总结页读取。 |
| `accuracy` | getter | B | 首答正确率，0 到 1。 |
| `QuizSession` | 类 | B | 运行一次测验。 |
| [`answer`](#answer) | 方法 | A | 判当前题目并保留结果。 |
| [`next`](#next) | 方法 | A | 进入下一题，并把答错的重新排队。 |
| `skip` | 方法 | B | 丢掉当前这道题，不作答也不记录。 |
| `summary` | getter | B | 已结束的会话。 |
| `_expectedText` | 方法 | B | 为界面给出正确答案的文本。 |

## 文档

### `QuizOutcome answer(QuizAnswer answer)` <a id="answer"></a>

- **种类：** 方法
- **用途：** 判当前题目并保留结果。
- **输入：** 学习者做了什么。
- **返回：** `QuizOutcome`，同时保留为 `lastOutcome`。
- **副作用：** 可能调用 `onFirstAnswer`；通知监听者。
- **算法：** 判分；若这是该条目的首次作答，则记录并回调；保留结果以便界面显示判定。
- **使用：** `QuizRunner`，学习者点击「检查」时。
- **说明：** **只有条目的首次作答会到达回调。** SM-2 评的是回忆的好坏，而一分钟内第三次才答对的条目并没有被回忆起来——记录这次重试等于告诉调度器学习者掌握了一个他们刚刚答错的词。回调按每次作答触发而不是结束时统一触发，因此中途被杀掉的应用仍保留已答的部分。

### `void next()` <a id="next"></a>

- **种类：** 方法
- **用途：** 进入下一题，并把答错的重新排队。
- **输入：** 无。
- **返回：** 无。
- **副作用：** 改变队列；通知监听者。
- **算法：** 丢掉当前题目；若它答错且重排次数少于 `maxRequeues`，则放到队尾。
- **使用：** `QuizRunner`，学习者点击「继续」时。
- **说明：** 这种重复正是学习发生的地方，而上限则防止一个难缠的条目让会话永远结束不了。与 `answer` 刻意分开：判分之后题目仍留在屏幕上，因为没被展示正确答案的学习者只会再猜一次，而不是学会。
