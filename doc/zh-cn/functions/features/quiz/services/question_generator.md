# lib/features/quiz/services/question_generator.dart

把一个目录条目变成一道题，用十三种模式中适合它的那一种。

**返回 null 是常态，不是失败。** 大多数词没有汉字，因此两种写法模式对它们不适用；大多数词没有例句，因此语法模式不适用；处在条目稀少级别的词可能凑不出三个像样的干扰项。调用方要什么就问什么、给到什么就用什么，这也正是逐条目尝试每一种模式、而不是事先挑好模式的原因。

行为描述见 [`../../../../features/quizzes.md`](../../../../features/quizzes.md)。

## 文档

### `QuizQuestion? forItem(String itemId, Set<QuizMode> modes, {required Locale locale, KanaScript script})` <a id="foritem"></a>

- **种类：** 方法
- **用途：** 用任一可行的已启用模式为一个条目构建题目。
- **输入：** 条目、学习者保留开启的模式、locale、字体。
- **返回：** `QuizQuestion?`——没有任何已启用模式适合该条目时为 null。
- **副作用：** 无。
- **算法：** 打乱已启用模式，逐个尝试，返回第一个能出题的。
- **使用：** `QuizPage`，对每个候选条目调用直到会话装满。
- **说明：** 之所以打乱而不是按序，是为了让同一个词不总是以同一种方式被问。逐个尝试并接受可行者，正是让同一组已启用模式同时服务于假名、单词与语法条目、而调用方不必知道谁是谁的原因。

### `QuizQuestion? _conjugation(GrammarPoint point, SentenceAnalysis analysis, String translation)` <a id="conjugation"></a>

- **种类：** 方法
- **用途：** 问句中该填哪个活用形。
- **输入：** 语法点、其已解析的例句、译文。
- **返回：** `QuizQuestion?`。
- **副作用：** 无。
- **算法：** 找出一个带有已恢复形式且活用类别已知的 token；向后扩展越过附着其上的每个助动词，得到书写形式；向活用器索取该词的全部四种形式；仅当其中之一恰好等于句子所写内容时才保留该题。
- **使用：** `_grammar`。
- **说明：** **一个活用形是好几个 token。** 分析器把食べます拆成携带已恢复ます形词干的食べ，以及作为独立助动词的ます——正是这种拆分让解析可行——所以形式必须在这里重新拼回。与句子自身文本比对是让题目诚实的关键：一个并非句子所写内容的「正确答案」会教错东西，因此活用器无法重现的词会被跳过而不是凑合。

### `QuizQuestion? _choice({...})` <a id="choice"></a>

- **种类：** 方法
- **用途：** 组装一道选项已打乱的选择题。
- **输入：** 条目、模式、题面、正确选项与错误选项。
- **返回：** `QuizQuestion?`——选项重复或为空时为 null。
- **副作用：** 无。
- **算法：** 合并、剔除重复与空串、打乱、记录答案落到了哪一位。
- **使用：** 每一种选择型模式。
- **说明：** 重复检查是最后一道防线，之所以放在这里而不是各模式里，是因为没有任何单一干扰项规则能为所有模式独自排除碰撞。两个相同的选项意味着两个正确答案，而一道有两个正确答案的题，比一道从未出过的题更糟。
