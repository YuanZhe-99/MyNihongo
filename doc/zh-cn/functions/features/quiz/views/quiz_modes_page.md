# lib/features/quiz/views/quiz_modes_page.dart

设置中按内容库分组、开关各种提问方式的页面。

与 WebDAV 页和备份页一样是二级页面：窄窗口全屏压栈，宽窗口承载于详情窗格，走的是同一套 `_SettingsDetail` 机制。

## 声明

| 声明 | 种类 | 层级 | 用途 |
|---|---|---|---|
| `QuizModesPage` | 类 | B | 模式开关。 |
| `build` | 方法 | B | 构建三组开关。 |
| [`_toggle`](#toggle) | 方法 | A | 开关一种模式，并拒绝关掉最后一个。 |

## 文档

### `void _toggle(BuildContext context, AppSettingsNotifier notifier, Set<QuizMode> enabled, QuizMode mode, bool on)` <a id="toggle"></a>

- **种类：** 方法
- **用途：** 开关一种模式，并拒绝关掉最后一个。
- **输入：** 当前已启用集合、该模式，以及它应处于开还是关。
- **返回：** 无。
- **副作用：** 持久化该集合，或显示一条消息。
- **算法：** 构造下一个集合；若它会变成空集，则说明理由并不作任何更改。
- **使用：** 本页的每个开关。
- **说明：** 拒绝时给出理由，而不是默默忽略。全部模式关闭就没有任何东西可问，而打开即空的测验看起来像坏了而不像被配置过——所以要告诉学习者开关为什么没有动。**已存储**的空集合含义相反，表示全部模式，这也正是本页按完整集合而不是按已存储内容绘制开关的原因。
