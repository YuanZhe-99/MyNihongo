# lib/features/quiz/widgets/quiz_runner.dart

在屏幕上运行一次会话：题目、作答控件，以及两者之间的反馈。窗口形状合适时分成两栏，否则堆叠；门控是 `canSplitLayout`，与应用里其他每处分栏所用的相同。

## 声明

| 声明 | 种类 | 层级 | 用途 |
|---|---|---|---|
| `QuizRunner` | 类 | B | 在屏幕上运行一次会话。 |
| `_submit` | 方法 | B | 提交已组合好的作答。 |
| `_continue` | 方法 | B | 越过反馈进入下一题。 |
| `build` | 方法 | B | 构建题目与作答控件，分栏或堆叠。 |
| [`_feedback`](#feedback) | 方法 | A | 说明作答是否正确，以及正确答案是什么。 |
| `_QuestionPane` | 类 | B | 屏幕上提问的那一半。 |
| `_instruction` | 方法 | B | 用文字说明学习者被要求做什么。 |
| `QuizModeLabel` | 扩展 | B | 用学习者的语言为测验模式命名。 |

## 文档

### `Widget _feedback(BuildContext context, AppLocalizations l10n, QuizOutcome outcome)` <a id="feedback"></a>

- **种类：** 方法
- **用途：** 说明作答是否正确，以及正确答案是什么。
- **输入：** 已判定的结果。
- **返回：** `Widget`。
- **副作用：** 无。
- **算法：** 用主色或错误色显示一个图标和一个词；答错时另附期望答案。
- **使用：** 位于作答控件与「继续」按钮之间。
- **说明：** 答错之后总是显示正确答案。条目会在会话内被重新排队，而没被告知答案就重排的条目只会被再猜一次，而不是学会。题面上方的说明文字出于相关的理由也用文字表述：活用题的空格和助词题的空格长得一模一样，因此题目的外形说不出在问什么。
