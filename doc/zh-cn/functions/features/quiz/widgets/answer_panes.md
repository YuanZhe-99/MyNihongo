# lib/features/quiz/widgets/answer_panes.dart

作答用的控件：四个选项、一个文本框，或可点击排序的片段。

在调用处只用一个控件而不是三个——三种作答形状是唯一变化的东西，而适用哪一种是题目自身的属性。

## 声明

| 声明 | 种类 | 层级 | 用途 |
|---|---|---|---|
| [`AnswerPane`](#answerpane) | 类 | A | 构建一道题所需的控件。 |
| `_ChoicePane` | 类 | B | 每行一个选项，整行可点。 |
| `_option` | 方法 | B | 构建一个选项按钮，作答后加以标记。 |
| `_TypedPane` | 类 | B | 输入读音用的文本框。 |
| `_OrderPane` | 类 | B | 可点击排序的片段。 |
| `_add`、`_remove` | 方法 | B | 把片段移入或移出句子。 |

## 文档

### `class AnswerPane` <a id="answerpane"></a>

- **种类：** 类
- **用途：** 构建作答所用的控件。
- **输入：** 题目、是否已锁定，以及组合与提交的回调。
- **返回：** 一个控件。
- **副作用：** 无。
- **算法：** 按题目的 `AnswerKind` 分派，并以题目身份作为 key——有 `questionId` 时用它，否则用 `itemId`，再加上模式。
- **使用：** `QuizRunner`。
- **说明：** key 很重要：题目切换时，组合中的状态——已输入的字符串、部分完成的排序——会被丢弃而不是带进下一题，这正是 key 换来的东西。它把 `questionId` 也算进去，因为一份卷子会围绕同一个词问好几道不同的题：只以条目为键的话，其中第二道会继承第一道输入了一半的答案。
  组合与提交是两个回调，因此点错可以纠正：选中一个选项只是选中，再做一个动作才提交。排序用点击而不是拖拽，因为在手机上一个片段宽的拖放目标是很难的手势，而点击可以再点一次撤销。
