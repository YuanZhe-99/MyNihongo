# lib/features/sentence/services/godan_rows.dart

五段动词活用所经过的五个假名行，由反向读取它们的去活用器与正向写出它们的活用器共享。

在 M3.2 需要正向活用时从 `deinflector.dart` 抽出。**只有一份**，因为两份最终会不一致，而拿一张与分析器所用不同的表来判分的测验会把正确的日语判为错误。

## 声明

| 声明 | 种类 | 层级 | 用途 |
|---|---|---|---|
| 库头 | 库文档 | B | 五段动词活用所经过的假名行。 |
| `godanURow` | 顶层常量 | B | 辞书形的末尾假名：行く、話す、飲む。 |
| `godanIRow` | 顶层常量 | B | ます所接的一行：行き、話し、飲み。 |
| [`godanARow`](#godanarow) | 顶层常量 | B | ない所接的一行：行か、話さ、飲ま。 |
| `godanERow` | 顶层常量 | B | 可能形与命令形的词干：行け、話せ、飲め。 |
| `godanClasses` | 顶层常量 | B | 全部五段类别，供调用方判断某个类别是否属于五段。 |

## 文档

### `godanARow` <a id="godanarow"></a>

`う` 动词取的是**わ**而不是あ——買わない，绝不是買あない。正是这一处不规则，使这些必须是表，而不能是从う段算出来的偏移。
