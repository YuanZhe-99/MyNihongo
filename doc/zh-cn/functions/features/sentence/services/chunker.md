# lib/features/sentence/services/chunker.dart

把词元归成文节，并猜测什么依附于什么。文节是一个实词加上所有依附于它的成分；日语依存关系描述在文节之间而非词之间，因为助词属于它前面的词并随之移动。

依附规则的推导见 [../../../../algorithms/sentence-analysis.md](../../../../algorithms/sentence-analysis.md)。

使用方：`sentence_analyzer.dart`。

## 声明

| 声明 | 种类 | 层级 | 用途 |
|---|---|---|---|
| `Chunker` | 类 | B | 把词元归成文节并建立依附关系。 |
| [`chunk`](#chunk) | 方法 | A | 把词元归成文节。 |
| [`_joins`](#joins) | 静态方法 | A | 判断一个词元是否延续当前打开的文节。 |
| `_build` | 静态方法 | B | 由词元区间构建一个文节：中心、标记、形式、是否谓语。 |
| [`_attach`](#attach) | 静态方法 | A | 猜测每个文节依附于什么。 |
| `_modifiesNoun` | 静态方法 | B | 判断一个文节是修饰名词还是修饰谓语。 |
| `_next` | 静态方法 | B | 找到某索引之后满足条件的下一个文节。 |

## 文档

### `List<Bunsetsu> chunk(List<Token> tokens)` <a id="chunk"></a>

- **种类：** 方法
- **用途：** 把词元列表变成 UI 所绘制的结构。
- **输入：** 按顺序排列的词元。
- **返回：** 按顺序排列的文节，已填好 `dependsOn`。
- **副作用：** 无。
- **算法：** 一趟扫描打开和关闭文节，然后调用 `_attach`。
- **使用：** `SentenceAnalyzer.analyze`。
- **说明：** 标点关闭当前文节且不并入其中，因此句末的句号不是某个词的一部分。

### `static bool _joins(List<Token> tokens, int i)` <a id="joins"></a>

- **种类：** 静态方法
- **用途：** 判断一个文节在哪里结束、下一个从哪里开始。
- **输入：** 词元列表与正在考察的索引。
- **返回：** 该词元延续当前文节时为 `true`。
- **副作用：** 无。
- **算法：** `Token.attachesLeft`，外加三种位置性情况：数字之后的量词、`suru-verb` 名词之后的动词 する，以及て形之后的动词。
- **使用：** `chunk`。
- **说明：** 这三种位置性情况是词元自身无法回答的。最后一种是普通动词充当助动词的唯一场合，也正是给词元赋类别时不读取目录 `auxiliary` 标注的原因——带该标注的动词在前面没有东西时仍然是动词。

### `static List<Bunsetsu> _attach(List<Token> tokens, List<Bunsetsu> chunks)` <a id="attach"></a>

- **种类：** 静态方法
- **用途：** 填入每个文节所依附的对象。
- **输入：** 词元与文节。
- **返回：** 一个新列表，已设置 `dependsOn` 并修正 `isPredicate`。
- **副作用：** 无。
- **算法：** 一律向右：修饰名词的文节依附到下一个体言文节，其余依附到下一个谓语文节，两者皆无时依附到下一个文节。最后一个文节是根。
- **使用：** `chunk`。
- **说明：** 修饰名词的文节**不是**谓语，即使它的中心是形容词。没有这条修正，句中的连体形容词会吸引它之前的每一个文节——于是时态检查会在一个完全正确的句子上误报，因为过去时间词依附到了一个不带时态的形容词上。
