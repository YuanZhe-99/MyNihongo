# lib/features/sentence/services/conjugator.dart

从辞书形构建活用形——与 `Deinflector` 方向相反，后者反向运行是因为解析本身就是反向的。

只做活用测验需要的四种形式：敬体、否定、过去与て形。刻意**不是**通用活用引擎——再多十几种形式，每一种都要有自己的例外，而目前没有任何东西需要它们。

两个方向共享 [`godan_rows.md`](godan_rows.md) 里的行表，因此测验绝不会拿一张与解析器不一致的表来判分。

## 文档

### `String? conjugate(String lemma, ConjClass conj, InflectionForm form)` <a id="conjugate"></a>

- **种类：** 方法
- **用途：** 写出一种活用形。
- **输入：** 辞书形、其活用类别，以及想要的形式。
- **返回：** `String?`——该类别不能取此形式，或该词看起来不像这一类别的词时为 null。
- **副作用：** 无。
- **算法：** 按类别分派；每个分支在变换之前先检查词尾。
- **使用：** `QuestionGenerator._conjugation`，经由 `allForms`。
- **说明：** **返回 null 而不是猜测，正是让测验保持诚实的做法。** 一个不是该词真实形式的干扰项会教错东西，而一道没有正确答案的题更糟，因此每个调用方在凑不出足够形式时都会丢弃该题。词尾检查不是多余的防御：分类错误的词条否则会产出看起来像日语、实际不是词的字符串。

### `String? _godan(String lemma, ConjClass conj, InflectionForm form)` <a id="godan"></a>

- **种类：** 方法
- **用途：** 变位五段动词。
- **输入：** 词、其类别、形式。
- **返回：** `String?`。
- **副作用：** 无。
- **算法：** 确认词尾是该类别的う段假名，去掉它，然后接上い段加ます、あ段加ない，或者て／过去词尾。
- **使用：** `conjugate`。
- **说明：** 不规则之处都在て形和过去形：末尾假名决定音变，浊音类取だ与で而不是た与て，而且**行く是一个行为像つ动词的く动词**——行って、行った，绝不是行いて。这项检查针对词尾而不是整个词，因此持って行く这类复合词也继承它。
