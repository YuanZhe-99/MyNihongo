# lib/features/sentence/views/sentence_lab_page.dart

句子实验室：输入一个句子，看看它由什么组成。位于 `/lab` 的全屏路由，在导航外壳之外。

功能描述见 [../../../../features/sentence-lab.md](../../../../features/sentence-lab.md)；本页记录各项声明。

使用方：`router.dart`。

## 文档

### `Widget build(BuildContext context)` <a id="build"></a>

- **种类：** 方法
- **用途：** 排布页面。
- **输入：** 构建 context；监听 `contentCatalogProvider`。
- **返回：** `Widget`。
- **副作用：** 无。
- **算法：** 一个位于 `pageMaxContentWidth` 的 `ConstrainedBox` 内的 `ListView`：输入框、分析按钮，然后是空状态提示或四个结果部分，最后是限制说明。
- **使用：** `/lab` 路由。
- **说明：** **在任何窗口尺寸下都是单列**，这是对应用惯常"放得下就分栏"规则的刻意例外，并已在 `adaptive-layout.md` 中如此记录。各部分是一条链——结构引用词，语法引用结构，问题引用两者——把引用放在被引用旁边会让阅读顺序变得含混。底部的限制说明是页面的一部分而不是一个提示气泡，理由与练习表相同：一个会猜测的工具必须在猜测被阅读的地方说明这一点。

### `Future<void> _generate(Future<String?> Function() request, void Function(_AiResult) store)` <a id="generate"></a>

- **种类：** 方法
- **用途：** 运行一次生成，并把结果放到界面读取的地方。
- **输入：** 要运行的 `request`，以及归档结果的 `store`。
- **返回：** 无。
- **副作用：** 在设备上运行模型；重建两次。
- **算法：** 先存一个加载中的结果，等待请求，再存文本或失败。
- **使用：** 全部三个 AI 操作。
- **说明：** 仅在本文件内使用的辅助函数。把「加载—结果」这套动作集中到一处，新增操作就不会忘了清掉自己的加载指示。null 回答被存为既无文本也无失败的结果，卡片把它措辞为「无法为此生成内容」——这是对一个跑完却没说出有用内容的模型的诚实描述，与错误是两回事。

### `List<Widget> _buildAiActions(...)` <a id="aiactions"></a>

- **种类：** 方法
- **用途：** 构建整句 AI 操作以及其下的卡片。
- **输入：** context、本地化对象、主题与分析结果。
- **返回：** `List<Widget>` —— 功能关闭时为空。
- **副作用：** 在使用按钮之前无。
- **算法：** 开关关闭时什么都没有；开启但模型未下载时给一行提示；否则给出按钮（忙碌时禁用），然后是已有的卡片。
- **使用：** `_buildResult`，位于最末。
- **说明：** 仅在本文件内使用的辅助函数。它们刻意位于所有确定性分节**之下**：分析才是这个页面，模型只是对它作评。三种状态各有理由——开关关闭时什么都不显示，让从未主动开启的学习者压根遇不到这个功能；模型可获取时给一行指向设置的提示，因为一个总是失败的按钮教出的是不信任而不是修好它的方法；而在根本无法运行模型的设备上同样什么都不显示，因为那里没有可修的东西，说了反而是空头承诺。
