# lib/features/sentence/widgets/grammar_used_list.dart

句子用到的已收录语法点：句子实验室的"用到的语法"一节。

使用方：`sentence_lab_page.dart`。

## 声明

| 声明 | 种类 | 层级 | 用途 |
|---|---|---|---|
| `GrammarUsedList` | 类 | B | 匹配到的语法点，每个都能打开其详情表。 |
| [`build`](#build) | 方法 | A | 构建匹配到的语法点列表。 |

## 文档

### `Widget build(BuildContext context)` <a id="build"></a>

- **种类：** 方法
- **用途：** 把句子用到的东西链回应用所教的东西。
- **输入：** 构建 context；widget 的分析结果与目录。
- **返回：** `Widget`。
- **副作用：** 点击某一行前无。
- **算法：** 把每个匹配的 id 解析为语法点，丢弃目录打不开的，然后显示句型、它的含义，以及匹配到的片段。
- **使用：** 实验室页面。
- **说明：** 各行打开与语法页相同的详情表，因此在这里注意到的句型与应用中其他地方用同样的措辞解释。空列表会明确说明，而不是什么也不渲染：没有用到任何已收录句型的学习者应当得到这个答案，而不是一处需要自行解读的空白。
