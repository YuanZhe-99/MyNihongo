# lib/features/sentence/widgets/token_chips.dart

句子被呈现为一排可点击的词色块：句子实验室的"词"一节。

使用方：`sentence_lab_page.dart`。

## 声明

| 声明 | 种类 | 层级 | 用途 |
|---|---|---|---|
| `TokenChips` | 类 | B | 句子的色块呈现，每个词一个。 |
| `TokenChips.build` | 方法 | B | 构建色块行，跳过标点。 |
| [`_chip`](#chip) | 方法 | A | 构建一个词的色块。 |
| `_open` | 方法 | B | 打开目录词条，或功能词自己的释义，经 `LocalizedStrings.lookupOrder` 解析。 |
| [`_label`](#label) | 静态方法 | A | 用用户的语言命名一个类别。 |
| `_colorsFor` | 静态方法 | B | 为某个类别选取主题配色。 |

## 文档

### `Widget _chip(BuildContext context, ThemeData theme, AppLocalizations l10n, Token token)` <a id="chip"></a>

- **种类：** 方法
- **用途：** 显示一个词、它经历了什么，以及它是哪一类词。
- **输入：** context、主题、本地化与词元。
- **返回：** 一个可点击的色块。
- **副作用：** 点击前无。
- **算法：** 三行：书写形式的表层、词被活用时的形式链，以及类别名称。
- **使用：** `build`，每个非标点词元一次。
- **说明：** **颜色从不是含义的唯一载体**——每个色块下方都写着类别名称，因此这种分组在色觉障碍读者和灰度截图下都成立。任何词典中都没有的词以错误色绘制*并且*标注出来，因为读者看不见的错误解析比看得见的更糟。

### `static String _label(AppLocalizations l10n, TokenCategory category)` <a id="label"></a>

- **种类：** 静态方法
- **用途：** 为学习者命名一个词元的类别。
- **输入：** 本地化与类别。
- **返回：** 六个名称之一。
- **副作用：** 无。
- **算法：** 一次把二十四个类别塌缩到六个的 switch。
- **使用：** `_chip`。
- **说明：** 六个名称对应二十四个类别是刻意的。读自己句子的学习者想知道某个词是助词；它是提示助词而不是接续助词，属于分块器的实现细节，把它印出来会让读者把注意力花在应用从未解释过的区分上。
