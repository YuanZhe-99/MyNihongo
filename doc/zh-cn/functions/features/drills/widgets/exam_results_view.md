# lib/features/drills/widgets/exam_results_view.dart

一份做完的模拟考试逐部分考了多少分，以及其中哪里出了问题。

它是应用里唯一一处显示一整份卷子成绩的屏幕，也是最容易被读成 JLPT 成绩的那一处。它在顶部用文字说明自己不是——而不是写在分数下面的一行小字里。

部分映射是传进来的，而不是在这里查出来的，因为画出这份卷子的页面已经有它了，在这里重新推导一遍意味着为了回答一个已经答过的问题去读四个内容文件。其余一切都来自做完的 [`ExamSession`](../services/exam_session.md)：用于计数的结果、用于取出做错那些题的文字的 `allQuestions`，以及每个计时部分的 `usedBefore` 与 `limit` 给出的用时。

使用方：`exam_page.dart`，在每个计时部分都交上之后。

| 声明 | 种类 | 层级 | 用途 |

| `ExamResultsView` | 类 | B | 一份做完的模拟考试逐部分考了多少分，以及其中哪里出了问题。 |

## 文档

### `Widget build(BuildContext context)` <a id="build"></a>

- **种类：** 方法
- **用途：** 构建逐部分的分数与做错内容的列表。
- **输入：** `context`；`exam`、`sectionOf` 与 `onDone` 字段。
- **返回：** 当前状态对应的组件树。
- **副作用：** 根据当前状态创建 UI 组件；从最后那个按钮调用 `onDone`。
- **算法：** 把每个计时部分的结果走成逐部分的 `(asked, right, missed)` 计数，同时收集每一条非正确结果的键以及它是否作答过。把计数求和得到全卷的分数。然后是一个 `ListView`：标题、分数、那条说明、按 `DrillSection` 顺序为每个有计数的部分各一行、每个计时部分一行给出它的用时与限时，以及——除非什么都没有做错——每个计时部分的 `allQuestions` 里 `scoreKey` 在错题列表中的每一道题，各自带着它「答错或未作答」的标签、它的题干、正确答案和一个 `WhyWrong`。一个完成按钮把它关掉。
- **使用：** `exam_page.dart`，在 `exam.isFinished` 之后。
- **说明：** 保持这个方法开销小，因为 Flutter 可能会频繁调用它。

  **未作答是与答错分开显示的。** 它们是两回事——一个是学习者做错的题，另一个是被计时拿走的题——而一个把它们合在一起的结果屏幕，会教学习者去复习他根本没见过的材料。逐部分的那一行只在确实有未作答时才把这个数字加上，所以一个全部作答的部分读起来就是一个朴素的分数。

  分数下面那条说明不是装饰：一个在 JLPT 几个字母旁边显示「67 题中的 48 题」的屏幕，除非它自己说明，否则会被读成一个 JLPT 成绩。

  `WhyWrong` 拿到的是 `chose: null`——一份模拟考试是在最后判分的，所以解析讲的是题目本身，而不是学习者当时选的那个选项。

  部分映射不认识其所属部分的题目会被跳过，而不是不带名字地计入，这与历史记录页遵循的规则相同。
