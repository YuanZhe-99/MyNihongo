# lib/features/drills/widgets/drill_passage_view.dart

阅读题所依据的那段文本：每个 `DialogueLine` 一行，内容提供了读音的地方带注音，译文放在一个开关后面。

译文做成开关而不是并排一栏，因为読解考的是读日文的能力——译文摆在文本旁边会把这项练习变成读英文。

译文用 `LocalizedStrings.resolveTranslation` 选取，因此日语读者——日语文章对他们没有译文——什么译文都看不到；当文章本身和它的任何一行都没有可展开的内容时，这个开关根本不提供。

| 声明 | 种类 | 层级 | 用途 |

| [`DrillPassageView`](#view) | 类 | A | 显示一篇文章，译文放在一个开关后面。 |
| `level` | 字段 | B | 改写要控制在哪个级别之内。 |

| `_paraphrase` | 方法 | B | 请求把一行用更简单的日文再说一遍。 |

## 文档

### `class DrillPassageView` <a id="view"></a>

- **种类：** 类
- **用途：** 显示一篇文章。
- **输入：** `passage`；`allowTranslation`——是否提供这个开关。
- **返回：** 一个组件（widget）。
- **副作用：** 无；开关是局部状态。
- **算法：** 一张卡片，每一行一块内容——内容写了说话人时显示说话人，日文用 `FuriganaText` 显示，展开时还有这一行自己的译文——其后是展开时整篇文章的译文，以及在允许**并且**文章或其中某一行对这位读者有译文（`resolveTranslation` 非空）时的那个开关按钮。
- **使用：** `quiz_page.dart` 的 `_passageFor`，作为阅读题在运行器中的前置组件。
- **说明：** 在计时部分里 `allowTranslation` 为 false。模拟考试要衡量的是学习者在没有辅助时能读懂什么，而译文正是那种能直接把大多数题目答出来的辅助。带说话人的一行按对话轮次排版；不带说话人的一行是一个段落——这就是会話与説明文的区别，内容文件通过写不写 `speaker` 来说明是哪一种。逐行译文与整篇译文都是可选的，并且在题目作答之前两者都保持隐藏。展开不了任何东西的开关不会提供：日语读者没有日语文章的译文。

端侧 AI 打开时，并且只在提供译文开关的地方，每一行都带一个按钮，请求把这句话用更简单的日文再说一
遍。它以 `allowTranslation` 为门槛，理由和译文一样：在计时部分里，把这道题所依据的那句话说得更简
单，几乎就是答案了。

改写就放在**它自己那一行下面**，而不是放在底部的卡片里，因为它的全部意义就在于让学习者同时看到一
句话的两个版本——而且它带着「生成」标签，因为这是模型写的日文，直接坐在应用写的内容下面，两者绝不
能分不出来。解析不了的回复会让这一行只剩原文：不会把半截解析出来的东西当作可以模仿的日文摆在学习
者面前。
