# lib/features/drills/models/drill_file.dart

解析一个练习题文件和结构文件，并把一道练习题变成测验运行器已经认识的形状。

一行格式有问题只赔上那一行，绝不赔上整个文件——与 `LessonPath` 的立场相同，理由也相同：这些文件是手写、手工合并的，一道坏题不能把一整个级别清空。

## 文档

### `enum ExamScale` <a id="scale"></a>

- **种类：** 枚举
- **用途：** 说明一场考试要考一份卷子的多少：每个大問约三分之一，还是官方的题目构成。
- **输入：** 无。
- **返回：** 无。
- **副作用：** 无。
- **算法：** 无；由 `LevelStructure.composition` 与 `LevelStructure.minutes` 读取它。
- **使用：** `DrillSource.scale`，以及考试页。
- **说明：** 它放在这里而不是放在考试会话旁边，因为知道怎么缩放的是*结构*——一份简化卷的题目构成是关于卷子的事实，不是关于运行它的那次会话的事实。`short` 是默认值：一份完整的 N1 卷子要 165 分钟，练习的意义在于常练，而一场没人抽得出一个下午来做的考试算不上练习。

### `static DrillQuestion? fromJson(Object? json)` <a id="qfromjson"></a>

- **种类：** 静态方法
- **用途：** 从练习题文件里解析一道题。
- **输入：** `json`。
- **返回：** `DrillQuestion?`——无法发问或无法作答时为 null。
- **副作用：** 无。
- **算法：** 拒绝没有 id、没有已知题型、没有 `items`、`kind` 未知、选项少于两个或存在空选项的一行。然后拒绝 `answerOrder` 不是其片段之排列的排序题，以及 `answer` 不是 `options` 有效下标的选择题。
- **使用：** `DrillFile.fromJson`。
- **说明：** 这些拒绝照搬了 `AuthoredQuestion.fromJson`，并加上了这种形状才可能出现的两条。不是排列意味着两个片段抢同一个位置，或某个位置没人认领——两种情况下句子都无法重建，也就没有可判分的对象。没有 `items` 的题目无法记到任何东西名下。`items` 从不为空，**第一个** id 是调度器看到的那个；其余的是薄弱点报告用来关联的，因为一个句子可能同时考两个点，而其中只有一个能拥有复习间隔。

### `QuizQuestion toQuizQuestion(Locale locale)` <a id="toquiz"></a>

- **种类：** 方法
- **用途：** 把它变成测验运行器已经会渲染的那种题目。
- **输入：** 用来确定书面文字的 `locale`。
- **返回：** `QuizQuestion`，其 `mode: QuizMode.drill`。
- **副作用：** 无。
- **算法：** 题目显示日文时，大字那一行是 `renderJa()`，否则是本地化后的提问；小字那一行是卷子的说明文字，只有当它上方有日文时才带上；除非题型要扣住读音，否则读音原样传过去；`speakText` 始终为 null。
- **使用：** `quiz_page.dart`，每抽到一道题一次。
- **说明：** 这是 `QuestionBank` 从未有过公开对应物的那个适配器，也是把卷子的惯例转成本应用惯例的唯一一处。阅读题的提问本身就是要作答的东西，所以把它做成空提示下方的一行灰色说明文字会把它埋掉。说明文字是逐题写的，因为卷子是逐个大問写的，而两个看起来一模一样的大問可能要求的是不同的事情。在读音**就是**答案的那两种题型里读音被扣住：在漢字読み题的 公園 上方印出注音等于直接把答案给了。每一道练习题的 `speakText` 都是 null——听力练习由 `ListeningScriptPlayer` 逐行播放，而一个用日语语音朗读本地化提问的发音按钮比没有还糟。

### `String renderJa()` <a id="renderja"></a>

- **种类：** 方法
- **用途：** 按这个大問显示日文的方式渲染日文。
- **输入：** 无；读取 `ja`、`blank` 以及题型的挖空样式。
- **返回：** `String`；没有日文时为空。
- **副作用：** 无。
- **算法：** 没有 `blank` 或它并未出现时，原样返回 `ja`；否则对挖空型题型把第一次出现替换成 `（　　）`，对标记型题型把它包进 `【…】`。
- **使用：** `toQuizQuestion`。
- **说明：** 空格是 `（　　）`，被标记的一段是 `【…】`，两者都是全角，因为卷子就是这么做的，真正去考试的学习者看到的也是这个。只处理**第一次**出现：一个把某个词说了两遍的句子问的是其中一个，把两处都挖空会改变题目。

### `static DrillFile fromJson(Object? json, {required JlptLevel level, required DrillSection section})` <a id="ffromjson"></a>

- **种类：** 静态方法
- **用途：** 解析一个练习题文件。
- **输入：** `json`，以及调用方所要的 `level` 与 `section`。
- **返回：** `DrillFile`——JSON 不是这种形状的文件时为空。
- **副作用：** 无。
- **算法：** 除非 JSON 是一个映射，且它自己的 `level` 与 `section` 都能解析成调用方所要的那两个，否则返回空；然后解析文章与题目，丢弃任何解析不了的行。
- **使用：** `DrillRepository.load`。
- **说明：** 级别与部分来自调用方，文件自称的那一份要与它们对照。一个顶着 N5 词汇的名字却说自己是 N4 语法的文件是一次合并事故，照样加载它会把 N4 语法当成 N5 词汇来计分。每个级别每个部分一个文件，平铺存放，这样一个部分可以在不动其他部分的情况下写作与评审，而整个第 4 阶段只让 `pubspec.yaml` 多一行。

### `Map<DrillType, int> composition(ExamScale scale)` <a id="composition"></a>

- **种类：** 方法
- **用途：** 说明该规模下的卷子每种题型各出多少题。
- **输入：** `scale`。
- **返回：** `Map<DrillType, int>`，不可修改。
- **副作用：** 无。
- **算法：** `full` 返回官方题量；`short` 返回各自的三分之一，向上取整，且不低于一。
- **使用：** 抽卷时的 `quiz_page.dart`，以及考试页。
- **说明：** 向上而不是向下取整，正是让卷子上每个大問都留下来的原因：只有一道题的大問的三分之一是三分之一道题，把它丢掉会悄悄变成完全不再考 情報検索。`minutes` 按同样方式缩放，所以简化卷每道题所受的时间压力与完整卷相同——而这份压力正是模拟考试区别于练习的主要所在。
