# lib/features/drills/services/drill_sampler.dart

从随包发布的文件里抽出一整份卷子的题目，而不会把同一件事问两遍。

它刻意是纯函数式的，随机源由外部注入，好让测试把它钉死。抽题是一场考试里最容易出错而又没人察觉的部分——一份每次都悄悄问同样六道题的卷子，看上去仍然像一份卷子——所以它可以被单独测试，而不是只能通过页面才够得着。

## 声明

| 声明 | 种类 | 层级 | 用途 |
|---|---|---|---|
| 库头 | 库文档 | B | 抽出一整份卷子的题目，而不重复已经问过的内容。 |
| `DrillSampler` | 类 | B | 为一份卷子抽题。 |
| `DrillSampler._` | 构造函数 | B | 阻止构造；所有成员都是静态的。 |
| [`draw`](#draw) | 静态方法 | A | 按卷子的顺序抽出一个部分的题目。 |
| [`drawByPassage`](#bypassage) | 静态方法 | A | 整篇文章地抽，而不是抽出散落在若干文章里的题目。 |
| `_pick` | 静态方法 | B | 从题池里取出最合适的 `want` 道。 |
| [`_order`](#order) | 静态方法 | A | 把从未问过的排在前面，然后是最久没问过的。 |
| `sectionsWithContent` | 静态方法 | B | 说明这一级别的卷子实际上有哪些部分是有内容的。 |

## 文档

### `static List<DrillQuestion> draw(DrillFile file, {required Map<DrillType, int> counts, Set<String> asked, Map<String, int> lastAsked, Random? random})` <a id="draw"></a>

- **种类：** 静态方法
- **用途：** 抽出一个部分的题目。
- **输入：** `file`；按题型给出的 `counts`；`asked`——学习者已经拿到过的每一个题目 id；`lastAsked`——每个题目上次被问的时间，以自纪元起的毫秒计；用于洗牌的 `random`。
- **返回：** `List<DrillQuestion>`，顺序即卷子发问的顺序，也就是 `DrillType` 里各题型声明的顺序。
- **副作用：** 无。
- **算法：** 先把文件里的题目按题型分桶，然后按顺序走一遍 `DrillType.values`，对题目构成要求的每种题型取 `_pick(pool, want, …)`。
- **使用：** 不带文章抽出的部分；`quiz_page.dart` 调用的是 `drawByPassage`。
- **说明：** `DrillType.values` 的顺序就是卷子的顺序，所以遍历它而不是遍历 `counts.keys`，无论结构文件里的题型映射碰巧以什么顺序写出，漢字読み都会排在文脈規定之前。某种题型的题目少于所要的数量时，就给出它有的那些：结果页会说明一共问了多少题，所以一个内容偏少的部分是看得见的，而不是被悄悄用别的题型补满。

### `static List<DrillQuestion> drawByPassage(DrillFile file, {…})` <a id="bypassage"></a>

- **种类：** 静态方法
- **用途：** 整篇文章地抽，而不是抽出散落在若干文章里的题目。
- **输入：** 与 `draw` 相同。
- **返回：** `List<DrillQuestion>`。
- **副作用：** 无。
- **算法：** 按题型把题池拆成有文章的题目和没有文章的题目。完全没有文章时，退回到对零散题目做 `_pick`。否则按排序单个题目的同一套办法给文章分组排序，整组整组地取，直到达到或超过所要的数量；如果分组先用完了，再用零散题目补足。
- **使用：** `quiz_page.dart`，用于抽出的卷子的每一个部分。
- **说明：** 一个読解或聴解的大問会围绕一段文本问好几道题。各自独立地抽题会让一份简化卷上出现分属四篇文章的四道题，也就是读四段文本只拿四分——是它所模仿的那份卷子的四倍工作量。所以抽取的单位是文章，它的那些题目跟着一起来。当一篇文章上的每道题都被问过时，这篇文章才算「已经问过」，而它的时近程度取的是其中最近被问过的那道题：学习者记住的是那段文本，而不是关于它的一道道题目。没有文章的题目单独抽，正是这一点让它可以安全地用于每一个部分——文章の文法有文章，文の文法1 没有，而两者都住在语法文件里。

### `static List<T> _order<T>(List<T> pool, bool Function(T) seen, int Function(T) when, Random rng)` <a id="order"></a>

- **种类：** 静态方法
- **用途：** 把从未问过的排在前面，然后是最久没问过的。
- **输入：** `pool`；`seen` 与 `when` 用来读取单个成员；`rng`。
- **返回：** 一个新的列表；输入不会被改动。
- **副作用：** 无。
- **算法：** 拆成未问过与问过两层，各自洗牌，然后把问过的那一层按时间戳排序。
- **使用：** `_pick`，以及 `drawByPassage` 对文章分组的排序。
- **说明：** 仅在本文件内部使用的辅助函数。**从未问过的在前，然后是最久没问过的，最后才是剩下的**——这三层的先后顺序很重要：一个已经见过某级别六十道题中四十道的学习者，应该被拿到他还没见过的那二十道；等题池用尽之后，最老的那道正是他最可能已经忘掉的。洗牌发生在每一层**之内**而不是横跨整个题池，这正是关键所在：单纯洗牌会让学习者昨天刚见过的题和他从未见过的题一样容易被抽中。稳定排序会把洗牌的效果保留在相同时间戳内部；Dart 的 `sort` 并不稳定，所以打破平局的是洗牌，排序只需要把不同时间戳之间的先后弄对即可。
