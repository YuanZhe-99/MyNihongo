# lib/features/drills/services/exam_session.dart

运行一份计时的 JLPT 卷子——它的各个部分、它的计时，以及那份让学习者可以先放下、之后再回来的保存。

计时是**注入**的，理由和 `QuizSession` 的回调一样：一个必须真等上好几分钟才能看到某个计时部分到点的测试，是没有人会去跑的测试。持久化是页面的职责，所以本文件不导入任何存储，测试可以原样读出本该被写下的内容。

只有当某个计时部分真正在屏幕上时，时间才会被计入。`usedBefore` 与 `resumedAt` 是这个数字的两半，正因如此，离开页面既不会让学习者损失时间，也不会白送时间——计时衡量的是投入的注意力，不是墙上的钟点。

保存的卷子被拆成两部分。`ExamSession.toJson` 写下它；`SavedExam` 把它读回来时**不去碰内容文件**，所以 Learn 卡片可以说出「N5 模拟考试，第 2 个计时部分，还剩 18 分钟」，而不必为此解析四个练习题文件。只有考试页会把一个 `SavedExam` 变回一个运行中的 `ExamSession`。

使用方：`exam_page.dart`（运行并保存）、`exam_results_view.dart`（读取已完成的计时部分）、`exam_provider.dart`（`savedExamProvider` 读取保存）。

## 文档

### `class ExamBlock` <a id="examblock"></a>

- **种类：** 类
- **用途：** 保存一个计时部分、它的题目，以及它的时间已经过去了多少。
- **输入：** 它在卷子里的 `index`；它考查的 `sections`；`limit`；运行其题目的 `session`；`usedBefore`——早先几次作答已经花掉的时间；`submitted`；`started`。
- **返回：** 一个由 session 驱动的可变持有者。
- **副作用：** 自身没有。
- **算法：** `used(now)` 是 `usedBefore` 加上——当 `resumedAt` 已设置时——自设置以来的时间；`remaining` 是限时减去它，下限截到零；`expired` 即 `remaining == Duration.zero`。
- **使用：** 由 `exam_page.dart` 构建——卷子的每个计时部分一个——并由结果视图读取。
- **说明：** `usedBefore` 与 `resumedAt` 是同一个数字的两半。只有当这个计时部分真正在屏幕上时时间才被计入，所以计时是「早先几次用掉的时间」加上「这一次已经进行了多久」——正因如此，离开页面既不会让学习者损失时间，也不会白送时间。

  `started` 与「计时正在走」**是两回事**，而这个区别很重要：每当页面弹出对话框或应用退到后台，计时都会停下；一个每次都退回到开始卡片的计时部分，在学习者看来就像卷子被扔掉了。

  `remaining` 之所以要截断，是为了让一个在应用被杀掉期间已经过了截止时刻的计时部分显示 `00:00`，而不是一个负的倒计时。

### `class ExamSession extends ChangeNotifier` <a id="examsession"></a>

- **种类：** 类
- **用途：** 运行一份计时的卷子。
- **输入：** `level` 标签；`scale`；`blocks`；`startedAt`；以及供测试用的 `clock`。
- **返回：** 一个供考试页监听的 `ChangeNotifier`。
- **副作用：** 在某个计时部分位于屏幕上时运行一个一秒的定时器；自身不持有任何存储。
- **算法：** 一个计时部分的列表，外加一个指向它的索引。当 `resumedAt` 已设置时当前计时部分的计时在走；一个一秒的定时器通知监听者并检查截止时刻。交上一个计时部分会放弃它的 `QuizSession` 中剩下的一切，并让索引前进。
- **使用：** `exam_page.dart` 构建一个、监听它，并在每次通知时保存。
- **说明：** 定时器**不**在构造函数里启动。卷子一被画出来就存在了，但它的计时必须等到学习者看过开始卡片并表示准备好之后才能走——一场在题目还在被读的时候就开始计时的考试，会比它所模仿的那场真考试更糟。

  持久化被刻意交给了别人：本文件不导入任何存储，所以测试可以原样读出本该被写下的内容。计时之所以被注入，理由和测验 session 的回调一样——一个必须真等上好几分钟才能看到某个计时部分到点的测试，是没有人会去跑的测试。

### `void resumeClock()` <a id="resumeclock"></a>

- **种类：** 方法
- **用途：** 开始或继续当前计时部分的计时。
- **输入：** 无。
- **返回：** 无。
- **副作用：** 启动一个一秒的定时器；设置 `started`；通知监听者。
- **算法：** 没有当前计时部分、它已交卷、或它的计时已经在走时，直接返回；否则打上 `resumedAt` 时间戳，把这个计时部分标记为已开始，并（重新）启动周期定时器。
- **使用：** 开始卡片上的开始按钮，以及考试页每次回到前台时。
- **说明：** **幂等。** 对一个计时已经在走的计时部分再调用一次不会改变任何东西，所以一个触发了两次的生命周期回调没法让卷子变短。

### `void pauseClock()` <a id="pauseclock"></a>

- **种类：** 方法
- **用途：** 停止计时，但不交卷。
- **输入：** 无。
- **返回：** 无。
- **副作用：** 取消定时器；把正在进行的这一次折进 `usedBefore`；通知。
- **算法：** 取消定时器；若有计时部分正在走，则设 `usedBefore = used(now)` 并清掉 `resumedAt`。
- **使用：** 离开页面与应用退到后台都会这么做；也是 `submitBlock` 的第一步。
- **说明：** 到此为止花掉的时间被折进 `usedBefore`，所以这份卷子之后被接着做时剩余时间还是一样的——计时衡量的是投入的注意力，不是墙上的钟点。定时器总是会被取消，即使没有任何计时部分在走，所以一份暂停的卷子不花费任何东西。

### `void submitBlock()` <a id="submitblock"></a>

- **种类：** 方法
- **用途：** 交上当前的计时部分并前进到下一个。
- **输入：** 无。
- **返回：** 无。
- **副作用：** 停止计时；放弃一切未作答的题；让计时部分索引前进；通知。
- **算法：** 没有当前计时部分或它已经交上去时直接返回。暂停计时、`session.forfeit()`、标记为已交，并在这不是最后一个计时部分时让索引前进。
- **使用：** 截止时刻检查、提前结束一个计时部分，以及这两者背后的定时器跳动。
- **说明：** 仍然没有作答的一切都被记为**未作答**，而不是记为答错。时间不够是这次作答的一个事实：把它算作答错会让每一个计时成绩都低于学习者的真实水平，而把它扔掉则会让每一个计时成绩都偏高。索引停在最后一个计时部分而不是越过末尾，这样在结果被阅读期间 `current` 始终有效。

### `bool checkDeadline()` <a id="checkdeadline"></a>

- **种类：** 方法
- **用途：** 计时走完时把这个计时部分交上去。
- **输入：** 无。
- **返回：** `bool`——它是否这么做了。
- **副作用：** 截止时刻已过时，与 `submitBlock` 相同。
- **算法：** 没有当前计时部分、它已经交上去、或者它还没到点时返回 false；否则 `submitBlock()` 并返回 true。
- **使用：** 计时的每一次跳动，以及考试页回到前台路上的生命周期回调。
- **说明：** 之所以在回来的路上也要检查而不是只在跳动时检查，是因为一部睡过了截止时刻的手机必须在醒来时发现这件事，而不是继续做一个二十分钟前就结束了的计时部分。返回值正是让页面在「继续计时」与「显示下一张开始卡片」之间做出选择的依据。

### `Map<String, dynamic> toJson()` <a id="tojson"></a>

- **种类：** 方法
- **用途：** 把卷子写下来，好让它之后能被接着做。
- **输入：** 无。
- **返回：** `Map<String, dynamic>`——保存的完整形状，由 `examSaveVersion` 标注版本。
- **副作用：** 无。
- **算法：** 只取一次 `now`。写下版本、级别、scale、开始时间和当前计时部分索引；然后逐个计时部分写下它的部分名称、它的限时、以秒计的 `used(now)`、它的两个标志位、它的题目 id——先是 `outcomes` 里已作答的那些，接着是 `session.remainingKeys`——以及来自 `session.chosen` 的答案，每个都经过 `encodeAnswer`。
- **使用：** `exam_page.dart`，在 session 每次变化时。
- **说明：** 题目是**按 id** 保存的，不是按内容：它们就在随包发布的文件里，而一份自带副本的保存会让人继续做一份应用本身已经不认可的卷子。答案保存的是学习者**选了什么**，所以继续作答时会按文件现在的样子重新判分。

  正在进行的这一次会先被折进 `usedSecs`，所以在一个计时部分进行到一半时取的保存记下的是实际花掉的时间，而不是到上次暂停为止的时间。

  `encodeAnswer` 表示不了的答案会被空值感知的条目丢掉，而不是写成 null，正因如此，一道打字作答的题在这里不花费任何东西。

### `static SavedExam? fromJson(Object? json)` <a id="savedexamfromjson"></a>

- **种类：** 静态方法
- **用途：** 读取一份保存的考试。
- **输入：** `json`。
- **返回：** `SavedExam?`——本次构建无法继续的一律为 null。
- **副作用：** 无。
- **算法：** 拒绝非 map，以及版本不等于 `examSaveVersion` 的。要求有级别和一个可解析的开始时间；通过 `SavedExamBlock.fromJson` 读取各个计时部分，丢掉失败的那些，并拒绝空列表。把 `blockIndex` 截进有效范围。
- **使用：** 供 Learn 卡片使用的 `savedExamProvider`，以及继续作答时的 `exam_page.dart`。
- **说明：** 版本号本次构建不认识的保存会被**拒绝，而不是读一半**。一场从只被部分理解的文件里继续的考试，会按它重建不出来的题目来判分，这比告诉学习者那份保存的考试没了更糟。在这条线以下则一律宽容：读不出的答案会被丢掉，对应的题目继续时是未作答的状态，而不是让整个计时部分作废；超出范围的计时部分索引则退回到第一个计时部分。
