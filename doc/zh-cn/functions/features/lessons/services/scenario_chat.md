# lib/features/lessons/services/scenario_chat.dart

情景脚本演完之后的自由对话，以及它的一轮。

刻意做成一个不带存储、也不带通知的普通对象：情景页面从建成那天起就没往磁盘写过东西，而一句脱离了情景的对话，不是会有人再打开来读的文字。页面关闭时，它随之消失。

使用方：`scenario_page.dart`。

设上限，是因为以角色身份作答的模型没有停下来的理由。八轮长到足以成为一段对话，又短到能在学习者还想继续的时候结束——而在此之前，`end` 随时可用，因为由学习者决定什么时候算说完了，正是对话与练习题的区别。

## 声明

| 声明 | 种类 | Tier | 用途 |
|---|---|---|---|
| `ScenarioTurn` | 类 | B | 一轮：学习者说的那句，或对方的回话。 |
| `ScenarioTurn.new` | 构造函数 | B | 保存这是谁的一轮、说了什么，以及可能的译文或校对。 |
| `learner`、`ja`、`meaning`、`proofread` | 字段 | B | 是谁的、说了什么、是什么意思、校对本会怎么写。 |
| `ScenarioChat` | 类 | B | 脚本之后的自由对话。 |
| `maxLearnerTurns` | 常量 | B | 对话收尾前学习者可说几轮（8）。 |
| `turns` | getter | B | 迄今说过的一切，从旧到新。 |
| `learnerTurns` | getter | B | 学习者已经说了几轮。 |
| `capReached` | getter | B | 学习者是否已用完所有轮次。 |
| `ended` | getter | B | 学习者是否自己结束了这段对话。 |
| `isEmpty` | getter | B | 是否还什么都没说。 |
| `addLearner` | 方法 | B | 记下学习者说的那句，连同可能的校对。 |
| `addReply` | 方法 | B | 记下对方的回话。 |
| `end` | 方法 | B | 结束对话，并丢掉说过的内容。 |

## 文档

`addLearner` 在请求回话**之前**调用，于是模型还在写的时候，学习者就已经在记录里看到了自己那句。`end` 除了标记结束，还会清空轮次：这里的内容本来就不打算留，而在学习者说了「说完了」之后还把记录留在屏幕上，会让人以为它留下来了。

这个文件不 import 存储、不 import provider，也不 import 进度模块。这与脚本那一半遵循的是同一条规则——见 `scenario.md`——也正是它让情景课是一节课，而不是一件会给你打分的东西。
