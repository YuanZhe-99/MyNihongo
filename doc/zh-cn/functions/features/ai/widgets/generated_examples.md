# lib/features/ai/widgets/generated_examples.dart

单词详情弹层里的**更多例句**操作，以及模型为它写出来的内容。

只在 Prompt API 真的能运行的地方显示，并且只在学习者点击按钮时才生成。打开弹层不会生成任何东西，生成的内容也不保存：这些例句只活到弹层关闭为止。每一条都带着本应用里所有生成内容都带的那个标签，放在文字上方而不是下方，好让它先于日语被读到。

使用方：`content_sheets.dart` 中的 `showVocabDetailSheet`。

在 `v0.4.3` 之前有两处问题，合起来被反馈为「AI 例句不工作」。这个部件通过一个普通的 `Provider` 读取 `canExplain`，而它不会因为 `notifyListeners` 重建；**并且**它位于一个只运行一次 builder 的 `showModalBottomSheet` 里——于是在 AICore 还在探测时打开的弹层，只要不关闭就一直看不到这个操作。现在它会监听服务，就像句子实验室从一开始就做的那样。另外 `_ask` 在提示词构建不出来时会静默返回，按钮看起来是坏的而不是不可用；现在它会说出来。

## 文档

### `Future<void> _ask()` <a id="ask"></a>

- **种类：** 方法
- **用途：** 请模型用这个词写例句。
- **输入：** 无；读取部件的 `entry` 与当前语言。
- **返回：** `Future<void>`。
- **副作用：** 在设备上运行模型；设置部件状态。
- **算法：** 等待提示词构建器，构建提示词，用资源里的 token 预算通过 `AiPracticeService` 运行，把回复解析成完整的例句并显示——或者显示一次失败。
- **使用：** 按钮，每次点击一次。
- **说明：** 无法解析成完整行的回复会被整条丢弃，而不是显示一部分：生成的句子就摆在目录自己的例句旁边，否则它看起来会和别人写的一样权威。现在每条路径都以「有例句」或「有提示」结束；这个方法原先那两处静默返回，和一个坏掉的按钮无法区分。
