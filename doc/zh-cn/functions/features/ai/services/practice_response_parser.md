# lib/features/ai/services/practice_response_parser.dart

读回模型写来的东西，并拒绝它读不懂的部分。

这里每一个解析器都返回 null 而不是一个尽力而为的猜测。一个无视格式的模型，其内容也同样不可信；而调用方的兜底——确定性的答案，或者干脆什么都不显示——比一个半解析出来的结果更好。

使用方：`why_wrong.dart`、`generated_examples.dart`。

## 声明

| 声明 | 种类 | 层级 | 用途 |
|---|---|---|---|
| `WritingFeedback` | 类 | B | 一段改写及其改动说明。 |
| `GradeVerdict` | 类 | B | 自由作答是否表达了同样的意思。 |
| `PracticeResponseParser` | 类 | B | 各个解析器。 |
| `maxNotes` | 常量 | B | 一份反馈最多带几条说明（3）。 |
| [`writing`](#writing) | 方法 | A | 读出改写及其说明。 |
| [`grade`](#grade) | 方法 | A | 读出「相同还是不同」的判定。 |
| [`examples`](#examples) | 方法 | A | 读出生成的例句。 |
| `explanation` | 方法 | B | 像实验室那样读出一段普通说明。 |
| `_after` | 方法 | B | 取出标签之后的内容。 |

## 文档

### `static WritingFeedback? writing(String raw)` <a id="writing"></a>

- **种类：** 方法
- **用途：** 读出改写及其说明。
- **输入：** 模型的回复。
- **返回：** `WritingFeedback?`——没有改写行时为 null。
- **副作用：** 无。
- **算法：** 第一条 `Rewrite:` 行，之后最多三条 `Note:` 行；标签匹配不区分大小写，半角与全角冒号都认。
- **用法：** 写作练习。
- **说明：** 改写是唯一必需的部分，因为它是学习者唯一能直接照做的部分。一个写出十条说明的模型已经不再遵守指令，而前三条是它最先想到的。

### `static GradeVerdict? grade(String raw)` <a id="grade"></a>

- **种类：** 方法
- **用途：** 读出「相同还是不同」的判定。
- **输入：** 模型的回复。
- **返回：** `GradeVerdict?`——首行不是这两个词之一时为 null。
- **副作用：** 无。
- **算法：** 把首行里除字母外的一切剥掉，要求结果是 SAME 或 DIFFERENT。
- **用法：** 自由作答评分。
- **说明：** 拖成一段话来打太极的回复会被拒绝，改由学习者自己判定——那本来就是没有模型的设备上会发生的事。**这个判定只是建议：** 真正进入调度器的，是学习者按下的那个按钮。

### `static List<ContentExample> examples(String raw, {...})` <a id="examples"></a>

- **种类：** 方法
- **用途：** 读出生成的例句。
- **输入：** 回复、译文所用的语言，以及一个上限。
- **返回：** 成功解析出来的例句；一句都没有时为空。
- **副作用：** 无。
- **算法：** 每行三个字段，以竖线分隔，半角与全角都认。
- **用法：** 词条 sheet 里的「生成例句」区块。
- **说明：** 字段数不是三个的行会被丢弃，而不是拿去猜。生成的例句与目录自带的并排显示，因此一句残缺的会看起来和真的一样权威。
