# lib/features/learn/widgets/today_card.dart

学习页的第一张卡片：学习连续天数、哪些到期、哪些是新的。也是回访的学习者不必滚动就该能读完的那一样东西。

它只陈述数字。对这些数字采取行动的按钮随 M3.2 的测验模式到来。

## 声明

| 声明 | 种类 | 层级 | 用途 |
|---|---|---|---|
| `TodayCard` | 类 | B | 显示今天有什么可做。 |
| [`build`](#build) | 方法 | A | 根据复习队列构建卡片。 |
| `_lines` | 方法 | B | 说明哪些到期、哪些是新的，或者什么都没有。 |

## 文档

### `Widget build(BuildContext context, WidgetRef ref)` <a id="build"></a>

- **种类：** 方法
- **用途：** 根据复习队列构建卡片。
- **输入：** `context`、`ref`。
- **返回：** 当前状态对应的控件树。
- **副作用：** 由当前状态创建 UI 控件。
- **算法：** 监听 `reviewQueueProvider` 与 `learnerProfileProvider`。先画一行带连续天数的标题，然后要么是进度条（队列仍为 null），要么是到期与新内容两行。
- **使用：** `learn_page.dart`，位于仪表卡片之上。
- **说明：** 队列为 null 时显示进度条而不是「没有待复习的内容」：这是两种不同的断言，而在数据加载完成之前只有一种为真。连续天数放在 `Expanded` 里而不是 `Spacer` 之后，因为「还没有连续记录——答一题就开始」比「连续 3 天」宽出好几倍，在窄屏手机上必须换行而不是溢出——这个溢出是英文冒烟测试抓到的，而中文布局测试当时全部通过。
