# 振假名对齐

要把假名印在汉字上方，就得知道哪些假名属于哪些字。内容库并没有说。它为每个词、每个句子各带一条读音——见
[`../data-formats.md`](../data-formats.md)——而没有任何东西把 学生 逐字映射到 がくせい。本文讲的是如何仅凭这两个字符串把映射还原出来，以及更重要的：它在什么时候拒绝。

## 问题

读音是一条平铺的字符串。表面则混着两类字符：读自己的，和不读自己的。

```
私は学生です          わたしはがくせいです
```

は、で、す 读自己；私 与 学生 不读。因此表面里的假名是**锚点**：每一个都必须按顺序、恰好出现在读音当前到达的位置上。两个锚点之间的一切，属于它们之间的汉字。整个算法就是这样，对多数词一遍就能定下来。

## 为什么一遍不够

```
母は                  ははは
```

把第一个 は 给 母，锚点之后还剩 はは，而锚点只消耗掉其中一个。对齐错了，剩下的那一个就是证据。取两个假名，母 = はは，锚点恰好消耗最后一个。反过来的情况也存在：

```
花は                  はなは
```

这里一个假名才是对的，因为 花 是 はな 而不是 はなは。局部没有任何信息能区分这两种情况——只有当读音被**完整消耗**，对齐才算数。所以搜索先给每个汉字段尝试最短的读音，不成立时回溯。

## 规则

- **按段，不按字。** 東京 只要一条读音，而不是每个字一条。逐字振假名需要逐字的数据，而这份数据并不存在；况且 東 也不是在每个词里都读 とう。
- **每个字至少一个假名。** 没有哪条读音比它覆盖的字还短，这是搜索的下界。
- **至多留给后面的段所需之外的部分。** 后面每一段都还要满足自己的下限，这是上界。
- **片假名只在比较时折成平假名。** テレビを見る 在内容里读作 てれびをみる，而表面仍显示 テレビ。除此之外不折叠任何东西：那是 [`toHiragana`](../functions/features/kana/models/kana_text.md) 在别处的职责，但那个函数会丢掉标点、改写长音符号，而对齐器匹配的是位置而不是声音。
- **标点、空格与测验的挖空符像假名一样充当锚点。** 它们在两个字符串里都原样出现。
- **々、〆、〇、数字与拉丁字母需要读音。** 日々 是 ひび，３時 是 さんじ；否则它们会去和并不存在的假名对齐。

## 失败也是一种结果

只要没有任何一种对齐能消耗完整条读音，`alignFurigana` 就返回 null：内容里没有该词的读音、读音属于该词的另一种形式、句子被规范化改动过。此时每个调用方都退回到有振假名之前的做法——读音另起一行、写在括号里，或者干脆不显示。

**这才是要紧的性质。** 错误的对齐不是更难看的排版，它把假名印在错误的字上，教出一个并不存在的读音。拒绝的代价是一行屏幕，猜测的代价由学习者承担。

## 开销

决定后续搜索的状态只有*（第几段，读到读音的哪个位置）*，因此一个已经失败过的组合日后不可能成功。失败的组合会被记住，搜索的复杂度由此被限制在 段数 × 读音长度，而不是随汉字段数呈指数增长。带十几个汉字段的句子能在一帧内画出来；没有这一条则会卡死。

## 活用形是特例

句子分析器给出的 `Token.reading` 是**辞书形**的读音：食べ 带着 たべる，因为词典里存的就是它，去活用也是拿它匹配的。把它印在 食べ 上，屏幕上会出现句子里没有的 る。所以 `surfaceReadingOfToken` 从词元自身的对齐里取汉字的读音，从表面书写取假名尾巴。

来る 是唯一一个常用的、汉字读音随活用而变的词——き、こ、く——而能判定的假名通常在**下一个** token 里，因为 来ます 被拆成 来 与 ます。判定交给已恢复的活用形；活用链无法判定时，chip 就不注音，而不是在学习者正要说 き 的地方印上 く。

## 给句子挖空

填空题会把句子的一段替换成 `＿＿`。它的读音必须失去同一段，否则句子上方的假名就把答案说了出来。`readingRangeFor` 把表面的一段映射到读音的一段：假名段是一个码元对一个码元，因此区间可以起止于其内部；而把汉字段拦腰截断的区间没有答案——とうきょう 的一半不是 東 的读音——这道题于是不带振假名显示。

## 用在哪里

| 显示的内容 | 读音来自 |
|---|---|
| 单词列表与词条详情里的词 | `VocabEntry.reading` |
| 语法点或假名下方的词 chip | `VocabEntry.reading` |
| 任何地方的例句 | `ContentExample.reading` |
| 测验题面，读音本身即答案的除外 | 词条，或挖空后的句子读音 |
| 句子实验室里的 chip | token，并按其活用形修正 |

开关在**设置 › 通用 › 汉字上方显示假名**，默认开启，且只在关闭时写入——这是全应用唯一一个反向存储的偏好，因为从没打开过设置的学习者，正是最需要读音的那一位。
