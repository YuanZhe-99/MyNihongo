# 应用商店文案

用于 Google Play 商店页与 GitHub 发布说明的文案，放在这里以便像其他内容一样被审阅，也让两处保持一致。此处不宣称

## 应用名称

MyNihongo!!!!!

## 简短描述（80 字符以内）

五十音、单词与语法参考。离线、无广告，可同步到你自己的服务器。

## 完整描述

MyNihongo!!!!! 是一款可以在地铁上打开、在折叠屏上阅读的日语参考应用。它离线可用，没有账号，除了你自行配置的
WebDAV 服务器之外，不会把任何内容发送到任何地方。

**内容**

- 完整的五十音图，两种字体，标出容易混淆的组合，并为每个假名提供示例单词。
- 7,700 个 N5 到 N1 的单词，基于 JMdict 与开放许可的 JLPT 词表构建，带读音、词性与释义。
- 81 个 N5 语法点，每个都有句型、接续方式、详解，以及带读音的例句。
- 三者之间的交叉链接：点开单词可看到其例句使用的语法，点开语法可看到其例句中的单词。
- 全部内容都可以由你设备自身的语音引擎朗读，并提供发音练习：把你说的与读音逐音拍作对照。
- 句子实验室：粘贴一个句子，看到词、什么修饰什么、用到了哪些已收录语法，以及有什么看起来不寻常。离线，无模型。
- 全应用支持英语、简体中文与繁体中文。中文释义覆盖 N5，其余显示英语。

**你的数据属于你**

- 没有分析工具、没有广告、没有崩溃上报、没有账号。
- 同步是可选的，只发往你自己的 WebDAV 服务器——Nextcloud，或任何支持 WebDAV 的服务。在你配置之前不会上传任何
  内容。
- 当同一个词在两台设备上都学习过时，应用会询问保留哪个版本，而不是悄悄替你选择。
- 带保留期限设置的本地备份，以及可以带走的 ZIP 导出。

**为折叠屏而做**

每个页面自行决定布局：窗口足够宽时两张五十音表并排，设置列表与详情窗格同屏，单词与语法列表的列数也可以自己设定。

**尚未提供**

发音练习、间隔重复复习与课程都在计划中。应用不会假装已经具备它们——“学习”标签会说明接下来会有什么。

基于 GPLv3 的自由软件。

## 更新内容（0.2.0）

全部内容都可以朗读，发音练习会把你说的与读音逐音拍作对照。新增的句子实验室会把句子拆解为词、结构与语法点。识别在你的设备上进行；一个默认关闭的开关是内容被发往系统语音服务的唯一途径。Windows 与 macOS 构建用于开发。

## 更新内容（0.1.0）

首个版本。五十音、单词与语法参考；带冲突处理的 WebDAV 同步；本地备份与 ZIP 传输；英语与简体中文。

## 数据安全声明

不收集数据，不共享数据。WebDAV 同步是用户自行配置、发往用户自有服务器的传输，按 Google Play 的定义不属于收集；
描述中会直接写明这一点，而不是留给用户自行推断。

会声明麦克风权限。它仅在学习者录制一次发音尝试期间使用，不保存任何音频，且识别默认离线——除非学习者打开网络回退，
描述与隐私政策都会说明这一点。
