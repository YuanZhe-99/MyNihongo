# 学习路径

Learn 标签页对「接下来做什么」的回答。一个级别被划分为若干单元，一个单元就是一个主题，每个单元装着它所教的语法与词汇、为它写的一些句子，以及为它写的一些题目。

各级别的参考列表与测验本来就能用。这条路径是穿过它们的引导路线；单元尚未编写的级别会用一行字说明，而不是显示一个空盒子。

## 一个单元

```
unit:n5-1  自我介绍
  grammar   9 个语法点
  vocab     22 个单词
  sentences 8 句，各自写明它教什么
  questions 8 道手写题，各自带说明
```

这些 id 与其他内容 id 一样是兼容契约：通过记录以单元 id 为键，而题目自己的 id 是故障报告要指名的东西。

**该级别的每个语法点恰好属于一个单元。** 有一条测试对照已发布文件断言这一点。不属于任何单元的语法点不是表格里的空缺，而是路径永远不会教的东西；属于两个单元的则被教了两遍，且哪一遍都没教完。

## 练习，以及它背后的题池

覆盖整个级别的测验会打乱该级别的条目并取二十道。这会让一种题型出现的概率取决于它的条目有多常见——用于复习没问题，用于一个主题则不对。

一个单元小到可以把事情做对。`QuestionBank` 会构建该单元**所有**能出的题：

- 它的每个条目，用每一种适用且已启用的模式；
- 它自己的句子，像目录例句一样跑过各语法模式；
- 为它手写的题目，也是唯一带说明的那些——

然后抽取十二道。重复的按题面去重，因为同一个句子从两个方向进入题池会被问两次。

抽取只按一件事加权：学习者还没答对的东西。没有记录的条目权重为三，只答错过的为二，其余为一，手写题权重翻倍——因为那是有人挑出来的。**每个条目至多一道题**：十二道题应该是十二件不同的事，而不是同一个词被问六遍。

## 单元测验

二十道题而不是十二道，而且它决定一件事：首答正确率达到七成即可解锁下一单元。这与总结页显示的是同一个数字，所以学习者能看出自己为什么通过或没通过。

单元测验是一道闸门而不是一个待复习条目，因此不走调度器。它的记录是一个纯计数器——通过几次、未通过几次——路径读的是 `correct > 0`。会话内部各条目的作答，在学习者作答时就已由普通路径逐条记录过了。

**锁定单元的测验仍然可以进入。** 在前一个单元通过之前练习是关闭的，但已经掌握这些材料的人可以直接测验并跳过去。把它藏在它本可以跳过的那些单元后面是循环的；而通过它唯一能做的事，就是解锁刚刚被证明掌握了的内容。

## 单元进度条量的是什么

该单元条目中至少答对过一次的比例。比调度器的视角更粗，而且是故意的：一条会因为间隔到期而倒退的进度条，是在为时间的流逝惩罚学习者。

从记录派生，从不存储——与每日计数遵循同一条规则。

## 文件

`assets/content/lessons/<level>.json`，每级一个，由 `lessonPathProvider` 按需加载。与在隔离区解析整个目录的 `ContentRepository` 分开：路径只是一个小文件，只有 Learn 标签页和一次会话会读它，而没有该文件的级别是一种普通状态而不是故障。

这些文件是怎么写出来的，见 [`content-authoring.md`](content-authoring.md)。

## 情景课

一个单元可以以一段**情景对话**结尾：六到八行，每行一个说话人，其中一到两处脚本会停下来问学习者该说什么。它跑在自己的路由（`/scenario`）上，从单元卡片里"练习"和"单元测验"旁边打开，每一行台词和每个候选回答都可以朗读。

有三条规则让它是一堂课而不是一次测验：

- **答错不会结束对话。** 脚本是线性的；学习者说的那句会以正确／错误的标记加进对话记录里它被说出的位置，并改变结尾显示的统计，别的都不改。说错一句就中断的对话，教不会人该说什么——而能在原位读到那句错的回答，正是值得读的部分。
- **脚本也不按选项分叉。** 每条分叉都要写、都要过门禁，那是每个单元都要付的内容成本，而这堂课的意义恰恰在于读一段真实的交流。
- **不碰调度器。** 从三个选项里挑一个不是回忆；回忆是在单元自己的练习会话里测量的。

已写了六段：N5 单元 1 到 4，以及 N4 单元 1 和 2。没有情景的单元不显示按钮，路径的其余部分不受影响。

## 写作练习

单元的 `writingPrompt` 会打开 `/writing`，学习者在那里写几句话，应用把它们解析出来：用到了本单元的哪些词（按**分词结果**统计，所以 食べました 也算用了 食べる）、每句是怎么被理解的、以及有哪些地方看起来不寻常。没有模型时，这就是整个练习。开启设备端 AI 后还会提供一个自然的改写版——见 [`ai-assist.md`](ai-assist.md)。两种情况都不写记录：一段话不是带回忆间隔的条目。
