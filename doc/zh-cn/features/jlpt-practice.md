# JLPT 练习

按真实卷子的形状编写的题目，一次练一个部分。学习标签页的 JLPT 卡片是入口：它写出学习者的目标级别，列出四个部分，并对每一个说明它有多少道题，或者为什么还不能练。

这不是 JLPT 卷子的复制品。历年真题版权归国际交流基金与 JEES 所有，这里没有任何东西是从真题里抄来的。被照搬的是**形状**：大問、它们的比例、计时部分的时长和计分组，这些都是 JEES 公布的。

## 卷子由什么构成

`assets/content/drills/structure.json` 里每个级别一条：计时部分及其分钟数、计分组，以及每个大問有多少道题。它自带一个 `source` 字段写明这些数字出自哪些页面，因为这些是别人公布的数字，而显示它们的界面应该说得出是谁的。

这些数字**刻意是近似的**。JEES 说题目构成每次考试都会变，所以这个文件是一个题目构成的目标，而不是对某一份具体卷子的承诺。

| 级别 | 计时部分 | 计分组 | 完整卷的题量 |
|---|---|---|---|
| N5 | 20 / 40 / 30 分钟 | 言語知識・読解, 聴解 | 67 |
| N4 | 25 / 55 / 35 分钟 | 言語知識・読解, 聴解 | 85 |
| N3 | 30 / 70 / 40 分钟 | 言語知識, 読解, 聴解 | 102 |
| N2 | 105 / 50 分钟 | 言語知識, 読解, 聴解 | 107 |
| N1 | 110 / 55 分钟 | 言語知識, 読解, 聴解 | 108 |

## 大問

一共二十一个，每个都属于四个部分中的某一个。**键**是内容文件写出的东西，也是兼容性契约；**部分**是它计分时归入的地方。

| 部分 | 大問 |
|---|---|
| 文字・語彙 | `kanji-reading` `orthography` `word-formation` `context` `paraphrase` `usage` |
| 文法 | `form-selection` `sentence-composition` `text-grammar` |
| 読解 | `short` `mid` `long` `integrated` `thematic` `info` |
| 聴解 | `task` `point` `outline` `expression` `quick-response` `integrated-listening` |

有三处刻意偏离真实卷子的地方，每一处都是因为应用自己的机制预设了卷子并不预设的事情：

- **即時応答 给四个选项；卷子给三个。** 作答控件、干扰项规则和门禁到处都假定是四个。
- **発話表現 用文字描述场景。** 卷子给的是一张图，而本应用的内容里没有图。
- **模拟考试中每道听力题只播一遍。** 练习中学习者想播多少遍都行。这是卷子的规则，而按一套更宽松的规则练习会养成考试要惩罚的习惯。

## 一道题是怎么显示的

词汇题或语法题显示它的日文；阅读题或听力题显示它的*提问*，日文则是旁边的那篇文章。

一道题所考的那段句子只写一次，写在 `blank` 里，再按大問来渲染：

- **挖空**——`（　　）`——用于 文脈規定、語形成、文の文法1、文章の文法：选项来填它；
- **标记一段**——`【…】`——用于 漢字読み、表記、言い換え類義：选项是关于已经在那里的东西的。

把其中一种渲染成另一种会改变题目，这正是它属于大問的属性、而不是逐题由人设置的字段的原因。

**漢字読み 与 表記 扣住注音**，因为在这两种题里读音*就是*答案。其余各处读音照样印在汉字上方，与应用里其他每一处一样。

每道题还自带一行说明文字，各种语言都有，因为卷子是逐个大問写说明的，而两个在屏幕上看起来一模一样的大問要求的是不同的事情：「＿の言葉の読み方」与「＿の言葉の書き方」是同一个句子标记了同一段。

## 计分，以及一道题按什么计分

一份卷子会围绕同一个词问好几道不同的题。所以一道练习题按**它自己的 id** 计分，而不是按它的条目 id——若按条目计分，关于 会う 的第二道和第三道题就永远不会被计入。

间隔重复的调度则反过来。每个**条目**每次会话只被告知一次，取的是问到它的第一道题：SM-2 评定的是一次回忆，而关于一个词的第二道题已经被第一道题预热过，因此它说明不了这个词掌握得如何。

卷子**不会因为一道题答错了就再问一遍**。重新排队是练习教人的方式，也恰恰是考试绝不能做的事：一份长度取决于做得好不好的卷子，没法按固定的题目构成来计分。

## 挑选要问哪些题

`DrillSampler` 分三层抽题：**从未问过的在前，然后是最久没问过的，最后才是剩下的**，并在每一层之内洗牌。一个已经见过某级别六十道题中四十道的学习者会被拿到他还没见过的那二十道；等题池用尽之后，最老的那道正是他最可能已经忘掉的。在一层*之内*而不是横跨整个题池洗牌，正是关键所在——单纯洗牌会让昨天的题和从未见过的题一样容易被抽中。

阅读与听力**按文章抽，而不是按题目抽**。一篇 中文 带三道题；各自独立地抽题会让一份简化卷上出现分属三篇文章的三道题，也就是读三段文本只拿三分——是它所模仿的那份卷子的三倍工作量。

题目少于题目构成所要数量的大問，就给出它有的那些。结果会说明一共问了多少题，所以一个内容偏少的部分是看得见的，而不是被悄悄用别的大問补满。

## 不能练习的部分

两种情况都是**禁用并把原因写在旁边**，绝不隐藏。一个找不到読解练习的学习者没有办法判断究竟是它不存在，还是自己没找到。

- 某个级别的某个部分还没有随包发布的文件时会如实说明。各级别是一个版本一个版本写出来的。
- 在没有日语语音的设备上，听力会如实说明。没人听得见的题目没有答案，这与应用自己的听力测验模式遵循的是同一条规则。

## 模拟考试

同样的题目，加上计时，在最后判分。有三点把它和练习分开，而每一点都是卷子自己的规则，不是一个设计选择：

- **一个计时部分要等学习者说开始才开始。** 一份卷子以一张开始卡片打开，写明这一部分、它包含哪些部分、它的分钟数和它的题目数量。给一个人还没看过的东西开始计时，不是在考日语，而真考试在各部分之间是有休息的。
- **卷子交上去之前什么都不判。** 没有判定、没有解析、没有继续按钮——作答即前进。每答一道就被告知结果是练习教人的方式，也是真考试最明显不会做的事。
- **一道听力题只播一遍。** 练习中学习者想播多少遍都行；模拟考试不行，因为考试不行。

时间用完的计时部分会被交上去，剩下的一切记为**未作答**——而不是答错。题目全部作答完的计时部分会被提前交上去，此时记录下来的用时就是实际花掉的时间。

### 计时衡量的是投入的注意力，不是钟点

只有当这个计时部分在屏幕上、并且应用处于前台时，时间才会被计入。一个去接电话的学习者并没有把那段时间花在卷子上；一个把它放了一整夜的学习者也没有丢掉这份卷子。离开页面或让应用退到后台会停下计时并把卷子写下来；回来时会以同样的剩余时间接着做——而且会先重新检查截止时刻，因为一部睡过了截止时刻的手机必须在醒来时发现这件事，而不是继续做一个几小时前就结束了的计时部分。

**已开始与正在走是两种不同的状态。** 每次打开对话框计时都会停下，而一个每次都退回到开始卡片的计时部分，在学习者看来就像卷子被扔掉了。这是这个功能曾经有过的一个 bug，是在设备上发现的，不是测试套件发现的。

### 一份保存的考试，而且它只留在这台设备上

应用目录下的 `exam_in_progress.json`——**不同步、不备份、不导出**。另一台设备上的一场未完成的考试没有意义：计时属于这一次作答，而半份卷子不是一个结果。备份与 ZIP 引擎只看得见注册表模块，所以待在注册表之外就是让它保持本地的全部办法。

保存里存的是题目的 **id** 和当时选了什么，从不存题目本身。继续作答时会按文件现在的样子重新判分，所以一次修正了答案键的内容更新也会连同继续的这份卷子一起修正；随包发布的文件里已经没有的题目 id 会被丢掉，卷子就少这么多道题，而不是拒绝打开。更新的构建写下的保存会被直接拒绝，而不是读一半。

Learn 卡片会先提出**继续**——写明级别、这一部分和剩余时间——然后才提出开一份新的。开始第二场模拟考试会先询问，因为每台设备只有一份保存的考试，而它是这里唯一一件找不回来的东西。放弃时会说明什么会留下：已经作答过的每一道题当时都已经过了复习调度，所以放弃丢掉的是卷子，不是学习。

## 结果历史记录

每完成一个练习部分都会记录为一次作答：哪个级别、哪个部分、问了多少题、答对多少，以及对每道题的第一次作答是什么。**仅此而已。**题目文字、它的选项和它的解析都在显示结果时从随包发布的文件里读回来，因此一次修正了答案键的内容更新，会连同历史记录一起修正。随包文件里已经没有的题目会用一行说明，而不是从这次作答里悄悄消失。

历史记录搭载在进度文件里，所以一台设备上的一次作答会出现在另一台设备的历史记录里，而删除其中一次会在下一次同步时到处删除它。保留四十次模拟考试和八十次练习；两个上限是分开的，这样一个每天练习、每月模拟一次的学习者不会丢掉每一次模拟考试。

**那里的分数不是 JLPT 成绩**，页面在顶部就说明了这一点，而不是留给人去推断：它是就这个应用问过的那些题目而言的。

作答历史记录也是阻止抽题器重复的东西。`asked` 与 `lastAsked` 是从**已同步的**作答推导出来的，因此两台设备会互相避开对方问过的题，而不是各自把同样的头二十道题磨一遍。于是保留多少次作答的上限，也就是一道题重新变得可问的那个点，而这是对「忘掉它」的一个合理定义。

## 内容

每个级别每个部分一个文件：`assets/content/drills/<level>-<section>.json`，平铺存放，外加 `structure.json`。由内容流水线的 `drills` 流撰写——见 `content-authoring.md`。每道题都写明它所关于的目录 id，而 `content_gate_test.dart` 会拒绝 id 不存在、位于更难级别，或重复了已被占用之 id 的批次。

随包发布的一切都是模型撰写、未经审校的，并且每个文件都在自己的 `source` 字段里如实说明。
