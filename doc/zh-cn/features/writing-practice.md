# 写作练习

对着一个题目写几句话，然后让应用检查。检查用的就是句子实验室自己的分析，每句跑一遍：词、结构、用到的语法，以及哪里看起来不寻常。设备上有端侧模型时，还会多一项改写。分析本身在
[`sentence-lab.md`](sentence-lab.md) 中描述，推导过程在
[`../algorithms/sentence-analysis.md`](../algorithms/sentence-analysis.md)；本页描述这个练习。

## 它在哪里

`/writing` 上的整屏路由，和句子实验室一样在导航外壳**之外**，理由也相同：它是对一份作业做的事，永远是带着目的进入的。

它从带有 `writingPrompt` 的课程单元进入——没有写作题的单元不显示这个按钮。题目和单元作为路由的 `extra` 传入，而单元正是让检查能够追问「学习者有没有用上本单元教的词」的东西。

## 它显示什么

**用学习者自己的语言写的题目**，然后是输入框，然后是**检查我的句子**。

检查会按日语句号切分所写内容，并逐句分析——分析器是为一次一句设计的。每一句都用同一个部件画出与句子实验室相同的四个带标题的部分；多于一句时会编号。

在它们上方，当练习来自某个单元时，还有一行**用了本单元多少个词**，目标是三个。这个计数来自**分词结果**而不是在文本里搜索，所以变形也算：写了 食べました 的人用到了 食べる。

在 `v0.3.2` 之前，本页只显示没有标题的词块和一份光秃秃的问题列表——没有标题，没有结构，也没有语法一节。用的是同一条流水线，只是呈现更薄，于是学过句子实验室的人在这里遇到的是同一份答案的更差版本。现在只有一个部件，两个页面不可能再各自漂移。

## 这里不评分

**不会为写得如何写入任何进度记录。** 一份写作不是带复习间隔的条目，学习者给自己的段落打分也不是调度器应当据以行动的事。用词计数看过即忘；解锁下一单元的关卡是该单元的练习环节，不是这里。

真正被写下的是文本本身，写进历史记录。

## 清单

在分析结果下面，应用会说出它测到了什么：写了几句、用了本单元的几个词、分析器找到了几个学过的语法
点、认得出的词里有多大比例处于目标级别或更简单，以及有多少词它根本读不出来。

这里每一项都是从**分词结果**里数的，不是在文本里搜的，所以变形也算——写了「食べました」的人用了
「食べる」。目录定位不到的词记为"读不出来"，而不是记为太难：不知道一个词是什么，和知道它超出了级
别，是两个不同的发现，只有后者是关于学习者的。而一个词都定位不到时级别比例取 1，因为一份因为查不
到某些词就责怪学习者的清单，测的是词库。

**其中没有任何分数，屏幕上也这么写着。** 没有总分、没有正确率、没有及格线，因为 JLPT 没有作文，为
它编一个分数等于应用断言了一件没有考官会断言的事。这项测的是"在自己能力之内"，不是"跟自己的级别一
样难"：一个以 N1 为目标的人写出的一整句 N5 词，整句都在 N1 或更简单之内，而奖励难度会推着学习者去
写超出自己的东西。

清单在每一台设备上都会运行。端侧 AI 打开时，它下面的按钮会问模型接下来可以试什么——而清单自己查出
的结果就在那条提示词里，所以模型看到的是测出来的东西，而不是被要求去测量。它的规则禁止重新评分。

## 历史记录

每次被检查的写作都会被记住，最新的在前；点一下就把它放回输入框并重新检查。窗口宽到可以分栏时，列表在输入框下方；窄时在顶栏按钮后面。

条目是**按单元区分**的：题目旁边的历史，是为*那个*练习写下的内容，因为同一句话为两个题目写下时是两份作业。只保存文本，不保存分析，也不保存任何生成内容。格式、由内容推导的 id 和一百条上限见 [`../data-formats.md`](../data-formats.md)。

## 可选的端侧模型

在**设置 › 端侧 AI** 打开后，会多出一个按钮提供改写。由哪个模型作答取决于设备有什么，两者说的话也不一样多：

| 可用的功能 | 按钮 | 得到什么 |
|---|---|---|
| Prompt | 改写得更自然 | 一份改写，外加几条关于它的说明 |
| 只有校对 | 给出改写建议 | 改写后的句子，仅此而已 |
| 都没有 | 不显示按钮 | 确定性检查，它本身就是完整的练习 |

校对这条路径是 `v0.3.2` 加的。在此之前按钮只由 Prompt API 决定，于是一台校对功能可用的设备——多数非 Pixel 硬件，包括 Galaxy Z Fold 8——什么也得不到。它**逐句**改正每个已分析的句子，因为 AICore 一次只服务一次推理；模型没有改动的句子原样带过。当所有句子都没有改动时，它会明说，而不是把学习者自己的文字当作改正还回去。

生成的一切都画在带「生成」标注的卡片里，位于确定性部分之下，且不会被保存。见 [`ai-assist.md`](ai-assist.md)。

## 布局

窗口可以分栏时分为两栏：题目、输入框、按钮和历史记录在左，宽度为 `labInputPaneWidth`，反馈占其余部分。分析各部分在任何尺寸下都留在那一栏内的单列中。已记入 [`../adaptive-layout.md`](../adaptive-layout.md)。
