# tool/merge_drafts.dart

Folds checked draft batches into the shipped content files.

The last step of the authoring loop, and **deliberately the dumbest**: every judgement about a draft
was made by `test/content_gate_test.dart` before this runs. All this does is merge, sort and write,
so that a batch which passed the gate lands byte-identically however many times it is run.

```
dart run tool/merge_drafts.dart gloss    tool/content/drafts/gloss/n4-*.json
dart run tool/merge_drafts.dart examples tool/content/drafts/examples/n5-*.json
dart run tool/merge_drafts.dart grammar --level N4 tool/content/drafts/grammar/n4-*.json
dart run tool/merge_drafts.dart units   --level N5 tool/content/drafts/units/n5.json
dart run tool/merge_drafts.dart drills  --level N5 --section reading tool/content/drafts/drills/n5-reading-01.json
```

Then, for the two vocabulary overlays:
`dart run tool/import_vocab.dart --overlay-only && dart run tool/convert_zh_tw.dart`.

## Documentation

### `void _mergeDrills(String assets, String level, String section, List<String> drafts)` <a id="drills"></a>

- **Kind:** function
- **Purpose:** Append drill questions and passages to a level's section file.
- **Inputs:** The assets path, the `level`, the `section`, and the draft paths.
- **Returns:** None; exits non-zero on a duplicate id.
- **Side effects:** Rewrites `assets/content/drills/<level>-<section>.json`.
- **Algorithm:** Read the shipped file if it exists, append every draft's passages and questions,
  strip any `zh_TW`, and write the whole file back through `_encoder` with its `schemaVersion`,
  `source`, `license`, `level` and `section` header.
- **Usage:** After a drill batch has passed the content gate.
- **Notes:** **Append, and fatal on a duplicate id.** Unlike the gloss and example merges, which
  overlay a value onto an entry that already exists, a drill question is a new thing each time.
  Silently replacing one would mean a re-run of a batch quietly discarded the first run's work, and a
  duplicate id would break the no-repeat sampler, which keys everything on the id. Exiting is the
  right response because the fix is in the draft, not here.

  `zh_TW` is stripped whatever the draft says. Traditional Chinese in the content is generated by
  `convert_zh_tw.dart` from the Simplified beside it and never hand-authored, so an agent that
  produced some was producing something that would be overwritten on the next run — and leaving it in
  would make `content_zh_tw_test.dart` fail on text nobody wrote deliberately.

  The `source` field is written, not copied: every shipped drill file says
  `model-authored (Claude), unreviewed` in its own text, so a reader of the asset learns where it
  came from without having to find this document.
