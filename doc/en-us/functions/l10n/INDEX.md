# lib/l10n/ — Generated Localization Code

The three Dart files in `lib/l10n/` (`app_localizations.dart`, `app_localizations_en.dart`,
`app_localizations_zh.dart`) are generated by Flutter's `gen-l10n` tool from the ARB catalogs
(`app_en.arb`, `app_zh.arb`, `app_zh_TW.arb`). They are tracked in source control but not hand-written, and — unlike
every other file in this repository — they carry no `/// Purpose:` Function Explanation Layer
comments.

`AppLocalizationsZhTw` is generated into `app_localizations_zh.dart` as a subclass of
`AppLocalizationsZh`, which is how a Traditional Chinese string that was never translated would
fall back to the Simplified one — `test/l10n_arb_test.dart` fails before that can happen.

Each locale subclass (`AppLocalizationsEn`, `AppLocalizationsZh`, `AppLocalizationsZhTw`) implements the abstract
`AppLocalizations` base class with one trivial string getter, or one method for a string with a
placeholder, per translatable key defined in the ARB templates. Because they are generated, not
authored, and contain no algorithm or usage beyond "return a localized string for this key," this
documentation set does not enumerate them individually. The canonical, human-maintained source of
truth for the string catalog is `lib/l10n/app_en.arb` (the template ARB file); regenerate this code
with `flutter gen-l10n` after editing any ARB file, per this repo's `AGENTS.md`.

| Source file | Kind | Declarations | Tier |
|---|---|---|---|
| `lib/l10n/app_localizations.dart` | generated abstract base + delegate | base class, `LocalizationsDelegate` lookup, `of(context)`, `lookupAppLocalizations` | B (generated) |
| `lib/l10n/app_localizations_en.dart` | generated locale subclass | one getter or method per ARB key | B (generated) |
| `lib/l10n/app_localizations_zh.dart` | generated locale subclass (both Chinese catalogs) | one getter or method per ARB key | B (generated) |

No declaration in this directory is counted toward the hand-documented declarations tracked in
[../INDEX.md](../INDEX.md); it is listed here for completeness of the function index only.
